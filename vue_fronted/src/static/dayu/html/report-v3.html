孤显右偏 · 略近低迷区
人生如钟摆——摆得过高是亢奋消耗，摆得过低是低迷麻木，都不持久；唯有回摆到中央"中和区"，能量才能细水长流。你这团火现在烧得有点静：内心略有低迷。对生活稳定的人来说这是平和，但也可能只是暂时的低沉期。火不缺柴，缺的是一阵风。
起风给自己一个小到不可能失败的挑战（7天晨间十形桩），先让火苗窜一下。
借风靠近高能量的人——赢者的火，是被别的火点着的。
防风低迷期不做大决定，先稳作息、稳节律，等摆回中和区再发力。
