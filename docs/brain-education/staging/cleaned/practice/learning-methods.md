### 0.1 教育观三句（复制天才的底层）

| 金句 | 交付用法 |
|------|----------|
| **学习就是为了应用** | 反对只为分数囤知识（书中借《三傻大闹宝莱坞》兰彻） |

| **快乐 → 成就 → 兴趣 → 成功** | 链路勿倒过来逼 |

另：Aal izz well（一切都会顺利）——乐观自我安抚话术，家长课可用，勿替代真实支持。

### 0.3 同一技能，五套学习顺序（绘画例 → 通用）

书中以绘画为例：**先本道找成就感，再相生，后相克**。可迁移到其它技能设计。

| 者型 | 第 1 步（本道） | 第 2 步（相生邻） | 第 3 步（相克 / 补短） |
|------|-----------------|-------------------|------------------------|
| **思者** | 创意（创新尝试） | 技巧（赢） | 功底（行） |
| **赢者** | 技巧（好表现、见成果） | 感觉（德） | 临摹补创意不足 |
| **德者** | 感觉（色彩/空间） | 功底（行） | 创意（思） |
| **行者** | 功底（扎实执着） | 临摹 | 技巧（赢）→ 自成风格 |
| **学者** | 临摹（快速学习） | 创意（思） | 感觉（德）→ 融入情感 |

顾问口诀：**成就感开口 → 相邻加持 → 相克补短**。

### 0.4 五力个性化训练顺序（复制期）

在「观察→专注→创造→想象→记忆」总通路之上，书中又给出**按本道优先**的打开顺序：

| 者型 | 训练顺序（书中） |
|------|------------------|
| 思者 | 创造 → 想象 → 记忆 |
| 赢者 | 想象 → 观察 → 专注 |
| 德者 | 观察 → 记忆 → 创造 |
| 行者 | 记忆 → 专注 → 想象 |
| 学者 | 专注 → 创造 → 观察 |

亦可五力按总序同时推进，但仍**加重本道**（与帐篷「最高柱」隐喻一致，见 theory §七 / 下文）。

### 0.5 潜能「帐篷五柱」与递减法则

- 五柱 = 创造 / 想象 / 观察 / 记忆 / 专注；出生时一根最高最粗 = **本道**
- 先用好最高柱 → 带动其它柱长高 → 大脑「容量」扩充
- **递减法则（书中）**：越晚教育，浪费越多（五岁左右教可激发大半；十岁后即使方法好也大打折扣——**教学叙事，需核实**）
- 狼孩等例：错过语言关键期难补 —— 强调窗口，**非恐吓家长**

五觉对应（与第四章一致）：思视 / 赢味 / 德触 / 行嗅 / 学听。

### 0.6 亲子属性：三种「爱」的变形

| 亲子关系 | 爱容易变成 | 机制（书中） |
|----------|------------|--------------|
| **同属性** | **纵容** | 优点一致；缺点自己看不见，也漠视孩子同款缺点 |
| **相生** | **伤害** | 用自己标准要求孩子（例：赢父母催思孩子要目标要快） |
| **相克** | **无奈** | 你要的刚好是孩子缺的（例：学父母严管德孩子要的是宽容情感） |

**处方总则**：先定位，再分析，后指导 ≈ 诊断 → 病理 → 处方。
欣赏最闪耀的那一力；给空间与互动语言——否则沟通只剩「挺好、随便、还行」。

完整沟通话术 → [talents-application.md](talents-application.md) §5。

## 一、第七章总览：天赋学习力与学习方法（精读）

> 对应书：**七、天赋学习力和学习方法**
> 结构：学习力分析（五者特质 · 家庭组合 · 家长五级）→ 学习方法（两日三记 · 三错一讲 · 学业规划 · 综合流程 · 考前）。
> 亲子内心戏 / 带法话术交叉见 [talents-application.md](talents-application.md) §5。

### 1.1 开篇定位

| 概念 | 书中口径 |
|------|----------|
| **总方针** | 每个孩子都是冠军；天赋不同 → **赛道不同** |
| **道 vs 术** | 学习**规律**是道；学习**方法**是术 |
| **三管齐下** | 提升大脑能力 · 改善学习态度 · 赋予提分方法 |
| **植入逻辑** | 学科规律高度总结 → 潜意识引导；短板用「相反暗示」逆转习惯；精准正面激励植入**心锚** |
| **结果观** | 提的不只是分数，更是人生选择权与精彩可能 |

```
学习力 = 态度 + 方法 + 能力
```

**金句**：顺应天赋因材施教，所有的孩子终成学霸。

### 1.2 左右脑学习总策略（分析开篇）

| 脑型 | 学习痛点 | 带法优先 |
|------|----------|----------|
| **左脑**（德 / 行） | 理解偏慢；练得多未必掌握；记不快 | **讲懂确认 > 盲目重复**；德者可推着学、持续增压；行者先疏通情绪再讲；多开口说 |
| **右脑**（思 / 赢） | 忘得快、答题「会的也错」；边学边玩效率低 | 先解决**目标 / 意义 / 梦想**态度；赢者奖励机制；思者梦想+榜样+优越感；自学要有明确动力 |

双减语境（书中）：时间已经够多 → 有效减负是提升意义与按天赋挖潜力，不是再堆时长。

## 三、家庭组合学习力

> 原书有「家庭组合学习力参数表」图，正文**未给出完整数字矩阵**；仅保留判定口径。

| 家长分 + 孩子分 | 含义 |
|-----------------|------|
| **≥80** | 学习上基本不用太担心 |
| **60–80** | 谁分低谁拖后腿 |
| **&lt;60** | 父母行动决定孩子学习结果 |

原则：未成年受家庭影响深；提升孩子学习力必须同时管**成人自己的情绪**。

### 3.1 居家因材施教

| 类型 | 建议 |
|------|------|
| 思 / 赢（右脑） | 思者有事可忙、赢者有「赚」（家务可发「工资」）；体力作家务 → 学习时专注够；**规矩 > 讲歪理**；赏罚清晰，可约翻倍后果并严格执行 |
| 德 / 行（左脑） | 多开口说、多关爱、多做主（点菜/购物/行程）；**讲道理 + 陪伴监督** |
| 学者 | 赏识第一；点到为止留面子 |

> **交付红线**：禁止体罚与人格羞辱。左脑「绝对不能打」；右脑书中「幼年打手板」实操一律改为规则 + 自然后果 + 即时奖惩。12 岁后更要以规矩与契约为主。

## 五、两日三记

> 脑力训练提单位效率 + 遗忘曲线节点刺激 + 三错一讲输出 → 过目不忘叙事。

海马体设记忆路径；反复刺激可启动 **LTP**（长时程增强）；海马偏**输出依赖** → 必须有「讲出来」。

### 5.1 三个必须节点

```
第1天课后：消化记忆 —— 记我学懂的，会记笔记
第1天晚上：立即巩固 —— 背我熟悉的，会再不错
第2天晚上：再次巩固 —— 讲我理解的，会能学透
```

不必每天低效狂复，而在关键节点加强输入。

### 5.2 脑波与情绪

| 因素 | 作用（书中） |
|------|--------------|
| **α** | 愉悦、平和、持久专注 |
| **θ** | 高兴趣/忘我时易出，助推 LTP（详见 [theory.md](../foundations/theory.md) 脑波节） |
| **杏仁核** | 情绪可刺激海马 → **情绪是记忆关键因素** |
| 无兴趣 | θ 消失；能力与意愿双降 → 恶性循环 |

### 5.3 提兴趣三招

1. **给意义与目标**（与生活/家人/成就感挂钩，如英语→出国无障碍）
2. **微启动**（先坚持 2–5 分钟，降低开始门槛）
3. **按天赋设奖励回路**（愉悦性奖励匹配五者）

## 六、三错一讲

依据学习金字塔（戴尔 / 缅因州训练实验室叙事）：**「教」才是真「学」**。

### 6.1 费曼四步（书中）

1. 选一个要理解的概念
2. 假设站在讲台教别人
3. 不能用简单几句说明 → 回去重学
4. 用最简单语言表达

### 6.2 每日操作

每天讲 **三道**错题 / 难题：分别来自**一天前、一周前、两周前**知识点；对父母或同学讲。
口诀：三个不会的，解开难度的，讲出总结的。

## 七、学业规划口诀

> 上课 ≠ 学习；上学 ≠ 读书；提分是主动学习力的结果。

**文理规律**

- 理科严谨如盖楼，循序渐进不跳跃
- 文科学好如捞鱼，知识大网反复扫

**理科三点**：定义、定理、定律先；听完回顾书，例题证明不马虎；旧的不会新不学

**文科**：通篇阅、过五遍；不懂不停步；理解兼联想，整体把握

## 八、学习力综合提升与流程

### 8.1 为何练「复杂处理」

书中：真正想要的是处理复杂知识 / 复杂工作的能力（重工业研发、桥梁、医药、航空航天等叙事）→ **面对复杂事物的学习力与创造力 = 核心生产力**。

布鲁纳（书中引）：无结构组织的知识易忘；按原理观念组织论据，是降低遗忘的已知方法。

### 8.2 最小循环

```
输入 → 检索 → 输出 → 应用场景扩大 → 更多输入需求
最小单元 ≈ 快速习题（极速学习）
```

右脑 ≈ 硬盘 + CPU；左脑 ≈ 搜索引擎；检索次数↑ → 匹配更准更快。

### 8.3 综合学习方法流程（有基础脑力训练后）

1. 整理学期科目与教材、习题、试卷
2. 科目清单：近期分 + 目标分
3. 刷卷计划表（**行者：不在量大，在知识点全面与深度**）
4. **输入**：翻书 → 影像追忆口述 → 提纲；检索课堂画面与旧题；当晚睡前再追忆（两日三记）；模糊→精确靠时间与专注
5. **输出**：听极速学习音频 → 限时答题记分；不纠结对错与左右脑，接纳分析与直觉
6. **三错一讲**：选三道错/难题；设想自己是老师怎么讲；可先列提纲；文理互借（理得清楚 × 讲得明白）
7. 扩充数据库、加强检索（专属「搜索引擎 + 百科」）
8. **自主安排一件家务 / 运动**
   - 右脑：简单重复持久劳动，或 >40 分钟有氧（练耐性）
   - 左脑：规划型事务（收纳、采购优先级等，练关联）
9. 收工犒劳自己

|------|------|--------|
| **对家长讲理念**（书第六章） | **快乐 → 成就 → 兴趣 → 成功** | 反对倒逼高压；先本道小胜、愉悦体验 |
| **对交付讲落地**（大会口径） | **可见小成绩 → 信心 → 乐趣** | 护航先做出可验收进步，再用成绩养信心 |

两套不打架：交付的「小成绩」必须落在**本道、短周期、可验收**上，才符合书本「成功催生成功」；禁止用恐吓式大提分承诺硬推「成绩→乐趣」。

### 附.3 文 / 理科闭环（补强第七章口诀）

**文科（识字前提下）**

1. 速读（超脑阅读）
2. 导图 / 影像追忆抓要点
3. 刷对应卷
4. 错题：标答案**关键词** → 用关键词**造句**（接近出题人思维）
5. 一书可：读→导图→刷卷多轮（「一天一册」属宣传，须核实）

拉开差距常在非标题（阅读/材料）；底座常是影像追忆。

**理科**：定义/定理/定律先夯实 → 解题思维 → 三错一讲；右脑易跳步马虎，左脑基础牢但大题思维要练。

### 附.4 刷卷与提速

- 现在刷是为了**以后少刷**；同分不同时 ≠ 同能力
- **唯快不破**：先激发速度，再按成绩补「会」；快但不会 ≠ 提分
- 训练极致叙事≈只剩书写时间（须核实）

### 附.5 阻碍孩子（顾问话术）

1. 伤仲永型：小学能力强 → 重点校后放飞 → 陪伴断
2. 「学生其实是父母」：家长懂不懂教育决定上限
3. 一锤子心态：只想花一次钱、家长不学
4. 未成年人不能自管命运
