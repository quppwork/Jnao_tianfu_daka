### 适用场景

- 大部分孩子和家长通过提分营进入体系
- 住校生：靠反复集训「波浪式」提分
- 走读生：日常 30–60 分钟 + 集训台阶式上升
- 初三/高三急提分：可在当地交付中心按小时加训

## 传承人体系

### 层级与收益

| 级别   | 条件             | 收益               |
| ---- | -------------- | ---------------- |
| 传承特使 | 4–5 次线下集训，表现不错 | 日薪 200 元         |
| 专利精英 | 能力达标           | 公司赠送原 6 万/30 万课程 |
| 超脑学神 | 顶尖小天才          | 日薪 500 元         |

### 设计意图

- 让普通家庭的普通孩子成为中国最聪明的一代
- 反对有钱家庭送孩子出国给「洋人打工」
- 优秀孩子不花钱，练得好还能回公司上班挣钱
- 有勋章、仪式、授勋，视为「比成人礼还重要」的命运转折点

## 专利精英

### 课程结构

- 八大职业分工：营销、企业管理、商务咨询、文案策划、招商策划、法务、艺术设计、产品研发
- 按天赋自然分工，形成小公司小组
- 涉及：科学竞选、文案技巧、项目路演、董事会、领导力
- 产出：实用新型专利、发明专利、外观专利

### 案例

- 学员连战：14 岁跟学，现英国世界 500 强工作；家长省培训费约 56 万
- AI 审核加速：发明专利六个月下证（过去需三年）

## 导师项目

### 导师权益

- 子女成长计划 + 3 年十期火箭提分营保障
- 优秀导师孩子四次集训后可成小助教，参加集训来挣钱而非花钱
- 成人课程、子女专属音频、专家指导、线上训练营、天赋课程
- 招商资格、零售资格、晋升督导/专家/主播/核心高管

### 导师要求（优先级）

1. 人品道德 > 敬业态度 > 专业技能
2. 分享助人 > 专业技能
3. 诚实真实 > 业务能力
4. 排斥：不择手段、只自学不教、光搞钱不管人

### 组织架构

- **四合一模式**：专家带多个导师
- **教育学院**：专家团带教
- **管理团**：张总 + 核心班子，教天赋运用
- **播商学院**：殷老师、李敏智老师主抓

### 晋升路径

```
入门导师 → 督导 → 专家/股东（公司上市分红，不用投钱）
```

### 收益参考（演讲数据）

- 专家导师团平均月入 1–3 万
- 实习底薪 2000；开干后底薪 5000–8000，优秀专家底薪 1 万
- 十人火箭提分营新人 → 课时费 5000 + 业务提成最高 5%

## 店铺与上市

- 店铺营业额达标 → 配原始股
- 店铺营业额划回总部，补税差，收入只多不少
- 纳入上市财务统计系统

## 商业理念（演讲表述）

- 「薪火相传」：导师体系不靠复购赚钱
- 公司有多项赚钱项目，教育核心是理念而非单次销售
- 两天可学会启动，但交付需约两个月
- 培养交付人才周期比市场人员长约 60 倍

### 天赋大书道

- **法 vs 道**：法=技巧形态；道=审美与底层规律
- **五者练字序（演讲）**：思偏灵动/草→行→楷；赢先行→楷→草→隶；德先楷→隶→行→草；行/学可循篆隶楷行草正统
- **五阶段叙事**：执笔扣墨 → 行笔呼吸 → 天人合一气息 → 精神立场 → 静心凝神
- **红线**：「15 天代替 15 年」「疗愈」勿写成医疗或保分承诺

### 无界外语（补强）

- 母语序：默语场景听懂 → 能说 → 识字读 → 写 → 译 → 考（与应试「单词→语法→考试」**倒序**）
- 依赖影像追忆、扫记、极速运算等能力集合；黑马营小班 / 家庭一对一更易跑通
- 思/赢最怕先背单词废掉语言天赋

### 火箭营交付心理（补）

- 五日常见弧：D1 观望 → D2 试配合 → D3 才真投入；勿把「第三天才用心」当成失败
- 「来玩」与「真想学」心态影响对抗长度

### 导师 / 传承人（补）

- 营/会约 3–6 次表现好 → **小助教**（参训不收费、可发工资叙事）
- 小 IP：效果好易被平台风控 → 策略改为低调
- 传承人战略叙事：主抓小学+初中，弱化高中应试窗口被占满的孩子
- 九段口径：九段「目前无人」、七段「很强」、五段≈学霸（演讲，须对齐培训标准）
