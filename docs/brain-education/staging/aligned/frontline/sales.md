## 一、总前提

家长已动心、孩子不愿来 → 往往不是「不需要」，而是「不想听你的」。

### 三原则

1. **不要试图说服孩子「学习很重要」** → 让他觉得「这地方好像不一样」。
2. **永远给选择权** → ❌「你必须来」 ✅「来不来随你，但我建议你来，因为……」
3. **让孩子觉得是自己决定的** → 开门，不硬推。

### 张宇核心逻辑三条

1. 不要改变孩子的想法，改变他的体验。
2. 不要证明你是对的，证明他是聪明的。
3. 不要卖课程，卖「三天没人管的自由 + 发现自己很牛的惊喜」。

## 二、孩子不想来的三大理由

### 理由一：亲子关系不好，为了反对而反对

- **诊断**：信用额度透支；通道堵死；内容再对也进不去。
- **错误**：家长自己苦劝；「妈妈为了你好」；单独逼一个；硬强调学习提升。
- **正确**：
  1. 第三方（销售/老师/孩子信任的哥哥姐姐）沟通
  2. 带朋友/同学一起来
  3. 话术改：「有个地方不用写作业，还能让你玩游戏变聪明，去不去随你」
  4. 强调好玩、交朋友、「发现自己原来这么牛」

**给家长：**

> 「你现在闭嘴，一个字都别说。……**这不是你的问题，是所有青春期孩子的通病——爸妈说什么都是错的，陌生人说什么都是对的。**」

**给孩子：**

> 「你不想去很正常……**你是不是觉得你妈不管说啥，你都不想听？** ……这个训练营跟你妈没关系，是你来，不是她上课。……顺便我再教你几个让你回学校能装逼的绝活。」

> 「……怎么**不学习还能考高分**。来不来随你……」

### 理由二：厌学不想努力，来就是受罪

- **诊断**：「学习」与「痛苦」焊死；「训练」被翻译成「受罪×2」。
- **目标**：不是说服「努力重要」，而是「原来可以不用那么努力」。

| 错误说法 | 正确说法 |
|---------|---------|
| 来努力三天，改变命运 | 来爽玩三天，顺便把下学期知识学完了 |
| 老师很严格，你会很辛苦 | 这儿没有老师骂你，只有你发现自己原来这么聪明 |
| 坚持一下，很快就过去了 | 如果你来了发现跟学校一样无聊，我马上让你回家 |

**核心话术：**

> 「……**真正会学习的人，从来不累。累的都是瞎学的人。**」

> 「……脑子里住着一个学霸，只是没人告诉过你开关在哪。」

> 「……**如果你第一天下午觉得没意思，你可以直接走**（按当期退费规则）。」

### 理由三：不相信，担心浪费时间

- **诊断**：被补习班伤害过多次 →「又一个骗子」。
- **四层动作**：
  1. 证据：视频、数据、老学员证言（姓名/学校/变化，合规授权后用）
  2. 零风险：线上短体验 / 先来半天 / 第一天不满意按规则退
  3. 同伴证言：同校同龄、最好认识的人
  4. 小步推进：先「看看」，再决定留下

> 「……**所以我不求你信我，我求你给我一个机会让我证明给你看。**」

## 三、终极话术（家长+孩子同时在场）

> 「我直说了。你们家现在的情况我大概清楚——**孩子不想听你说话，你觉得孩子没救了，两个人互相折磨。** 这个训练营不是来救孩子的，是来给两个人『放假』的。孩子来这几天，没人管他，没人逼他，还能学几个绝活；家长回去歇几天，别打电话、别问学习、别查岗。**几天后再见，孩子可能还是那样，但至少你们几天没吵架，这值不值？**
> 如果孩子来了，发现真的有用，那是意外收获。如果发现没用，你就当花了钱买了几天清净。**怎么算，你都不亏。**」

## 四、沟通铁律（摘要）

1. **共情 → 价值 → 轻引导**（先对齐感受，再给方法，最后给行动）
2. **术语变通**：对外少甩内部黑话；思者→创造型/鹰，赢者→领袖型/狮……（详见 [talents-application.md](../practice/talents-application.md) 对外称号）
3. **三镜模型**（talent_stories）：透视镜（知己知彼）→ 聚光镜（聚焦需求）→ 放大镜（放大需求）
4. **五者成交偏好**（故事库口径，作参考）：思者定心｜赢者定业｜德者定事｜行者定技｜学者定位
