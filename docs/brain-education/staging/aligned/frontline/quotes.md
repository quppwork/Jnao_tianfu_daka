## 一、教育本质

| 金句 |
|------|
| 没有能力不学方法。 |
| 能力是地基，刷题是上层建筑。 |
| 今天任何一个单一能力都不可能让孩子有效提分。 |
| 学校是选人不是教人。 |
| 学习像吃东西：入口、胃部消化、营养吸收，三阶段缺一不可。 |
| 只有文字带来从文字到图像的转化，这才是脑力训练。 |
| 不改变学习状态，只不断提高能力。 |
| 解决学习要有五个力：愿力、脑力、毅力、心力、效力。 |

## 二、五者口播

| 金句 |
|------|
| 人的天赋不同，像鹰/狮/象；学校却用同样方法教不同孩子。 |
| 右脑型永远是态度问题，左脑型永远是脑子问题。 |
| 德者逼则进、放则退；像大象——有压力是麒麟，无压力是傻狍子。 |
| **思者**天赋是最不喜欢学的；核心在**监管（规矩+条件约束）**，不在空讲道理。 |
| 行偏赢＝学霸天赋：上手快，持续提分到接近满分。（宣传口径，须核实） |
| 用管学者的方法管思者＝耽误孩子；思者要规矩，学者要赏识。 |
| 学者孩子只要夸；伸出大拇指赏识教育。 |

## 三、亲子沟通

| 金句 |
|------|
| 到四年级有问题就是教育出了问题，不可能是孩子脑子有问题。 |
| 承认他有病的一刻，比真有病还可怕（终身负面暗示）。 |
| 你们立的家规都是你们第一个打破的。 |
| 永远不要抱怨孩子；孩子所有问题都是你的问题。 |
| 只要换一个家庭，他就会改变。 |
| 父母不改变＝白搭；训练再好，两个月打回原形。 |
| 本自具足：你本来要相信他有。／越想要越没有＝不断强化「得不到」。 |

---

## 四、学习态度

| 金句 |
|------|
| 两个差孩子，只要解决态度这一个维度就无敌了。 |
| 态度有了分数天天提；态度没有再切分都没用。 |
| 态度五档：100%做老师／80%全力／60%听话／40%勉强／20%掉车尾必须退学。（内训口径） |
| 准时上班准时下班＝混日子；不对训练负责＝最严重态度问题。 |
| 一定是他求我我才能帮他，不是我求他。 |
| 态度＝现金：学习态度＝成绩，工作态度＝收入。 |

---

## 五、训练与潜意识

| 金句 |
|------|
| 训练本质＝无时无刻高要求；不这样人就会退化。 |
| 答案必有解；万物皆有所用；不怀疑，不放弃。 |
| 所有能力训练到极致都是「病」；天才与神经病一步之遥——练差不多就行。 |
| 选择性遗忘是超强好能力；记吃不记打＝逆商。 |
| 付的是满汉全席，非要吃十个汉堡。／单一能力维度太窄，风险太高。 |
| 亲子关系是潜意识最大风险。（详见 training §九） |
