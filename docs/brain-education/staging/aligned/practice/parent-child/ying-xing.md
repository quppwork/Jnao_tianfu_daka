> 来源：同事《赢者妈妈×行者孩子_沟通方案》。场景以**训练营招生**为主。
> 破局关键：**不要把训练营卖成「学习」，卖成「游戏闯关 + 赚钱/赢」。**

## 1. 适用

| 项 | 内容 |
|----|------|
| 典型学段 | 小学 / 初中（坐不住、爱玩） |
| 常见卡点 | 妈妈要结果，孩子怕「来就是受罪」 |
| 家长心理 | 要赢、要面子、要看得见的变化 |
| 孩子心理 | 把「训练营」自动翻译成「补习班 = 坐着受罪」 |

## 2. 核心冲突

```
赢者妈妈：结果 / 效率 / 赢 / 面子 →「争点气」「给我赢回来」
        ↓
行者孩子：好玩 / 刺激 / 即时反馈 → 静止=痛苦，运动/竞争=兴奋
        ↓
妈妈越强调「去学习」，孩子越不来
```

**真洞察**：行者不是不想来，是**标签错了**。

> **口径**：本方案中的「行者」属**好动偏赢型**（主行+外显精力/竞争）。理论主画像另有「封闭务实」一面——招生用本卡，日常封闭型见 [../talents.md](../../foundations/talents.md) §2.4 与 [../talents-application.md](../talents-application.md) §5.4。

## 3. 错误 vs 推荐

| 错误 | 推荐 |
|------|------|
| 「你能不能争点气」「你得给我赢回来」→ 逼学习 | 「您要说『去赢』，别说『去学习』。」 |
| 「去学习三天」 | 「**千万别说『去学习的』，要说『去玩的』。**」 |
| 「花钱了必须学出点东西」 | 「您越强调『学』，他越反抗。您强调『赢』，他越投入。」 |
| 「他就是不爱学习」 | 「他不是不爱学习，他是不爱『坐着不动』。行者需要动起来学。」 |

### 给妈妈的助攻金句（原话）

> 「儿子/女儿，妈妈给你报了一个三天的训练营，不是上课的，是闯关打比赛的。你不是喜欢PK吗？那儿有人跟你比。你赢了有奖励，输了也不亏。去不去随你，但妈妈觉得你可能会喜欢。」

关键：①不是上课 ②闯关打比赛 ③赢了有奖励 ④去不去随你

### 给妈妈金句

1. 「行者型的孩子，不是在课上变强的，是在比赛中变强的。」
2. 「他不是懒，他是行者。逼鱼爬树，他当然反抗。」
3. 「这三天不学习，玩三天。但玩的是动脑子的游戏。」
4. 「您要说『去赢』，别说『去学习』。」
5. 「行者孩子第一天下午就不想走了，因为这儿比家里好玩。」

### 给孩子金句

1. 「这儿不是上课，这儿是打游戏。」
2. 「我们不看书、不记笔记、不刷题。我们只闯关。」
3. 「你不是喜欢赢吗？这三天让你赢个够。」
4. 「打游戏是虚拟的赢，这儿是真实的赢。」
5. 「你既能玩，又能赢，还能让你妈闭嘴。」

## 4. 招生脚本

### 对赢者妈妈

> 「姐，我知道您要什么——**您要的是结果，是赢……** ……行者型来了，效果往往最明显。……**巧了，我们这儿不学习，我们玩三天。**」

> 「……**您孩子不是懒，他是行者。行者的孩子，大脑就是在动中学习的。** ……逼鱼爬树……」

### 对行者孩子

> 「……**这儿不是上课，这儿是打游戏。** ……不看书、不记笔记、不刷题。我们只做一件事——**闯关。** ……积分……排行榜……团队赛……单挑……**你赢得多，奖励就多。**」

> 「……**我这儿没有『坐那儿不动』这个选项。** ……**你不是喜欢赢吗？这三天让你赢个够。**」

> 「……不叫它『学习』，我们叫它『训练』。……**这三天，比你打三天游戏还爽。因为打游戏是虚拟的赢，这儿是真实的赢。**」

### 卡壳速查

| 卡壳 | 应对 |
|------|------|
| 「不爱学习怎么办」 | 「不爱坐着不动；需要动起来学。」 |
| 「不就是补习班吗」 | 「补习班坐着听课，我们站着比赛。」 |
| 「怕光顾着玩」 | 「玩中学效果最好；越投入进步越快。」 |
| 「去了能干嘛」 | 「PK、闯关、积分、排行榜；赢了当场有奖励。」 |
| 「花钱必须学出东西」 | 「强调『学』→反抗；强调『赢』→投入。」 |

### 一句话总结

> 「赢者的妈，你别催他学习，你催他去赢。行者的娃，这儿不是上课，是打游戏闯关——赢了当场有奖励，输了也不亏。你来三天，比打三天游戏还爽。」

## 5. 顾问 / 智能体红线

- 对妈妈：给「赢的确定性」+ 可见变化；可提退费规则，避免绝对「包赢」分数承诺
- 对孩子：禁用「学习/补习班」标签；只用闯关/比赛/积分/奖励语言
- 妈妈角色：从「逼迫者」转为「赞助商」
- 禁止「你必须给我学出点东西」当场加压
