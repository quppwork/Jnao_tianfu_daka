## 九、脑力训练注意事项（第十章精读 · 安全手册）

> 来源：《超脑进化之书》**第十章「脑力训练注意事项」**（二次精读核对）。
> 书中经验：约**每训练五个孩子**，至少会出现下列一类现象之一；全脑训练负面口碑，多因**出现问题却不会处理**。
> **交付原则**：先停损 → 再分流（换项目 / 降强度 / 上报）→ 全程留痕；医疗问题转医生，极端心理问题转专业人士。

### 9.1 生理类

#### 9.1.1 大脑神经类（「聪明疼」/ 睡眠紊乱）

- **现象**：极细神经痛，俗称「聪明疼」——像牙疼不是病，疼起来要命；大脑兴奋度过高、神经高度活跃
- **书中比喻**：突然能徒手捏破玻璃杯，却因力道失控扎破手 → **能力增长过快或过强的过程性损伤**
- **书中解释口径**：亦有「突触增加链接、脑力提升过程中产生疼痛」一说（作教学比喻，不作医学诊断）
- **四档处理（书中原文口径）**：

| 档 | 做法 | 一线落地 |
|----|------|----------|
| **快** | 潜意识引导，关闭神经痛信号 | 仅有资质老师按内训流程做 |
| **中** | **换做感知类训练**，开发新的神经网 | 与「高敏感须停感知」不同场景：此处是为神经痛换通路；勿与 9.1.2 混用 |
| **慢** | 保持当下训练节奏 + 药物止痛（书中举例布洛芬等） | **非处方建议**；用药必须遵医嘱；书中称疼痛通常不持久 |
| **外力** | 更高阶课中的潜意识用法 | 一线禁止自行发挥 |

伴睡眠紊乱时：优先查是否**晚间仍高强度训练**（见 9.3 动态失衡）。

#### 9.1.2 多元感知类（高敏感 / 感知幻觉）

| 情况 | 处理（书中） |
|------|----------------|
| **感知高敏感** | **立刻停止**感知类训练（如极速导读等右脑感知开发）；改**照相机记忆 / 极速运算**等。原因：感知力训练属右脑开发，与高敏感互相作用 |
| **感知幻觉** | 视为潜意识觉醒征兆（感知训练右脑开发 → 自动跳到潜意识应用）→ **马上进入潜意识训练**；若已造成内心恐惧：家长须先学专业知识，再做潜意识**安全引导** |

书中口径：只要不是亲子关系问题，多数相对好解决。

#### 9.1.3 分泌激素类（情绪失控 / 运动过度）

- 训练强度过大、成长过快 → 激素分泌过旺
- **处理**：运动可加速激素消耗；发现孩子**焦躁、暴力**时，先让孩子去运动，再评估是否降强度

### 9.2 心理类

#### 9.2.1 意识觉醒类（问题加重 / 幻视幻听）

**问题加重**

- 往往是**以前积累的问题暴露**（内心渴望的情感、游戏、手机等），不是训练「凭空制造」
- **处理方向**：家长来学习专业知识；可用训练设备辅助与保护（书中：设备既能帮孩子，也能护孩子）

**案例要点（书中·山西三年级）**

- 背景：父母没空管教 → 沉迷电视游戏 → 厌学、不交作业；父母来学习后情况好转
- 现象：厌学「瘾」具象成人物，威胁「写作业就伤害父母」
- **案例说明**：不是训练制造问题，而是**暴露隐藏的家庭关系**
- **话术方向（须内训脚本）**：把「瘾」定义为坏蛋；下定决心不再玩游戏后，坏蛋消失、不会伤害父母
- **红线**：禁止一线自由发挥恐吓话术

**幻视幻听**

- 潜意识觉醒变强 + **惊恐**常见
- 家长须学专业应对，**切勿只陷负面情绪**
- 书中建议：孩子可多读国学经典（经史子集等）正向文本

#### 9.2.2 人格意识类（逃避 / 自我否定）

- **意识逃避**：多属自身与**生活环境**问题；书中举例：蓝鲸等邪恶游戏更易在受过伤害的人群起效（伤痛易被诱发）
- 家长需专业学习
- 顾问须切记：**面对的并非都是健康家庭**，存在极端可能
- **遇极端：第一时间反馈专业人士**，禁止拖延或私下「扛」

#### 9.2.3 原生家庭类（心理创伤 / 负面植入）

- 潜意识会**放大**正面与负面信息
- 潜意识训练中**切忌投射负面信息**（怀疑、否定、嘲讽）
- 开启大脑的同时必须**心灵滋养**

### 9.3 脑波类

| 类型 | 现象 | 处理要点（书中） |
|------|------|------------------|
| **动态失衡** | 昼夜颠倒 / 多动难抑 | 脑力训练会兴奋大脑 → **勿在晚 10 点后训练**；白天过动、晚上过沉：可阶段性「隔约 40 分钟叫醒一次、过渡约 1 小时」（执行须家长知情、注意安全） |
| **高度活跃** | 眨眼焦躁 / 幻觉频繁 | **先天天才儿童**相对易见；降强度 + 观察 + 必要时上报 |
| **脑波异常（专注低）** | 无法自控的分心 | 除**学者**外四者都可能；右脑多因贪玩懒，左脑常非故意；书中口径：此类多属**天赋决定，训练不能根治**，靠持续练习惯、加强控制力提效 |

### 9.4 关于训练「稳定性」（极易被忽略）

书中核心机制：

1. 课上有老师督促 + 音频/设备，材料与讨厌的课本关联弱 → 潜意识未必跳出来对抗
2. 课后孩子独自面对**讨厌记的知识**时，能力可能被潜意识过滤 → **选择性遗忘**启动，痛苦低效记忆又回来

因此：训练场景愉悦 ≠ 面对讨厌课本仍能调用能力。必须同步解决：

- 学科愉悦度 / 意义感
- 亲子认同与信任
- 迁移验收（真实作业 / 课本）

详见上文 8.3 影像追忆稳定性风险。

### 9.5 营养素补充（书中方向 · 非医疗处方）

> 仅作知识库备查；具体补充方案须营养师 / 医生指导，**禁止顾问自行开「药单」**。书中数据与功效表述需独立核实。

| 方向 | 书中提到的要点 |
|------|----------------|
| 视神经与脑能量 | OMEGA-3 不饱和脂肪酸、EPA、含 DHA 的食物；必需脂肪酸与胎儿/婴儿脑视力发育相关论述；孕期沉积量等数字见原书（引用时须核实） |
| 神经传导 | 脑神经细胞卵磷脂约占质量 **17%–20%**；胆碱（大豆卵磷脂成分）与「乙酰」合成乙酰胆碱（书中：大脑信息传导物质），从而提高脑细胞活性化、记忆与智力水平（书中口径） |

视力修复与脑力通道关系见 8.4。

### 9.6 亲子关系＝潜意识最大风险

#### 9.6.1 为什么是最大风险

- 潜能开发远不止学习力，实质是**人一生的课题**；亲子关系是一切关系的基础
- 潜意识训练过程中，**最大风险是亲子情感关系**
- 能伤人最深的人，常是最亲的人；伤害发生时，潜意识相当于植入**反向操作指令**，会被如实执行 → **事与愿违**
- 书中心理咨询常见：父母子女**相爱却不相知**、互不理解又相互责怪；孩子可能强颜欢笑，也可能歇斯底里、无论父母做什么都不领情 → 沟通障碍埋在潜意识里未被正确觉察

#### 9.6.2 训练现场怎么被植入

- 训练环境多为**居家**；陪练者（通常父母）的**心理状态、思维状态**是孩子第一感知到的信息
- 人对负面信息的接受度往往大于正面；孩子天然看重父母态度，对隐性信息敏感
- 父母内心带着怀疑、否定、不信任 → 会被优先感知并同步植入潜意识 → 可能造成伤害
- 出于自我保护，孩子会**主动拒绝或屏蔽输入** → 训练效果变差

#### 9.6.3 能量水平与成人先自调

- 书中引用霍金斯「意识能量层级」观点：**能量水平决定能力水平**（引用须注明出处与边界，不作玄学化承诺）
- 处理亲子问题时：情绪会互相影响；措施**从来不只考虑孩子**，更重要的是**成年人自己的情绪状态**
- 潜意识相关训练期间：保护好孩子、保持好亲子关系、有效沟通；成人主动寻求正向、积极、平和；给孩子的力量与鼓励**不能只停在口头**，要发自内心的真诚与认同

#### 9.6.4 顾问动作 checklist

1. **开训前**：先做亲子关系评估（可对照家长五级，见 [learning-methods.md](../practice/learning-methods.md)）——书中收束句：「在做一切测试和训练之前，先来进行一次亲子关系的评估吧。」
2. **课中**：陪练者情绪异常 → 先停练、先修复关系
3. **异常现象**：按 9.1–9.3 分流；极端心理 **立即上报**
4. **全程**：正向语言、禁止负面投射、留痕

### 9.7 一线老师「遇事怎么办」速查

```
出现异常
  ├─ 疼痛 / 睡眠乱 → 9.1.1（快/中/慢/外力；用药问医生；查是否晚练）
  ├─ 高敏感 → 立刻停感知类，改照相机记忆 / 极速运算
  ├─ 感知幻觉 → 进潜意识训练 / 安全引导；恐惧则家长先学
  ├─ 焦躁暴力 → 先运动消耗，再评估强度
  ├─ 问题加重 / 幻视听 → 家长学习 + 设备保护；脚本内应对
  ├─ 逃避 / 自我否定 / 极端 → 立刻专业人士
  ├─ 晚练兴奋 → 禁止 22:00 后训练
  └─ 课上会、课后不会 → 查稳定性 + 亲子 + 学科愉悦度
```
