> 破局关键：**让妈妈退后一步，让孩子觉得「这是我自己选的」。**

## 1. 适用

| 项 | 内容 |
|----|------|
| 典型学段 | 高一 / 高二（心智较成熟） |
| 常见卡点 | 妈妈管不动、孩子逆反、销售卡壳 |
| 家长心理 | 「不是不想让他来，是管不动了。」 |
| 孩子心理 | 「不是不想变更好，是妈的方式让我反感；我要自己决定。」 |

## 2. 核心冲突

```
德者妈妈：安全感 + 规则 + 确定性 → 唠叨 / 重复 / 讲大道理 / 控制
        ↓
思者孩子：自主 + 被理解 + 选择权 → 越被安排越反抗
        ↓
信用额度透支 →「你说什么我都不听」→ 僵持
```

**通病**：德者唠叨模式 = 思者触发器；讲大道理对高中思者无效。

## 3. 错误 vs 推荐

| 错误 | 推荐 |
|------|------|
| 亲自苦口婆心劝 | 「你现在要做的第一件事——**闭嘴。不是放弃，是换个人来跟他说。**」 |
| 「我花钱了，他必须去」 | 「你越这么说，他越逆反。……你退一步，他进一步。」 |
| 「为你好」加压 | 「**你的任务不是说服他，是给他一个台阶。**」 |
| 催促犹豫中的孩子 | 「这时候你不能催，你一催他就反悔。」 |

### 给妈妈的助攻金句（原话）

> 「儿子/女儿，妈妈不逼你。但我觉得那个老师说得有道理，你要不要去看看？就算不满意，也就一上午，没什么损失。妈妈尊重你的决定。」

拆解：①我不逼你 ②老师说得有道理 ③去看看不满意就走 ④我尊重你的决定

### 给妈妈金句

1. 「你不是无能，是孩子长大了。」
2. 「思者越逼越反抗，你越给他安排，他越觉得你不信任他。」
3. 「你在他那里的『信用额度』已经透支了。」
4. 「你的任务不是说服他，是给他一个台阶。」
5. 「这不是放弃，是策略。」

### 给孩子金句

1. 「我不是来劝你的，我是来给你信息的，你自己判断。」
2. 「我们不刷题、不背书、不重复。我们教的是怎么用你的大脑。」
3. 「为什么你同桌好像也没怎么学，成绩却比你好？因为他有方法，你在硬撑。」
4. 「来不来随你，但你没什么可失去的。」
5. 「这不是你妈让你来的，这是你自己决定要不要试试的。」

## 4. 招生三步脚本

### 第一步｜稳住妈妈（退后）

要点原话：

> 「张姐，我先问你——**你是不是觉得说什么孩子都不听，越说越烦？** ……这不是你的问题，是思者到了高一高二的通病。**思者的孩子，越逼越反抗。** ……你管不动，不是无能，是孩子长大了，他需要觉得『这是我自己选的』。」

> 「你是德者，想掌控、想安排……他是思者，要自主……需求是反的……**信用额度已经透支了。**」

> 「……**闭嘴。不是放弃，是换个人来跟他说。** ……把电话给他，或者说『有个老师想跟你聊聊，你不来也行，听听看』。然后你就走开。」

### 第二步｜直接对话思者孩子

> 「……**我先声明——我不是来劝你的，我是来跟你聊几句，然后你自己决定。**」

> 「……**我们不刷题、不背书、不重复。** ……我想让你**聪明地学，而不是拼命地学。**」

> 「……**来不来，你自己决定。** ……**这不是你妈让你来的，这是你自己决定要不要试试的。**」

### 第三步｜妈妈间接助攻

交付上方助攻金句，然后闭嘴。

### 卡壳速查

| 卡壳 | 应对 |
|------|------|
| 「我已经劝不动了」 | 「所以你需要我。你越劝，他越不来。你闭嘴，我来。」 |
| 「我妈就是烦……」 | 「巧了，我也不是来听你妈的。我是来跟你聊聊，你自己决定。」 |
| 「担心来了不认真」 | 「思者一旦自己决定要来……最认真……在验证『是不是真的有料』。」 |
| 「之前去过类似没用」 | 「先听一上午，不满意就走。……最多浪费两小时。」 |
| 「花钱了必须去」 | 「你越这么说，他越逆反。……你退一步，他进一步。」 |

### 一句话总结

> 「德者的妈，你别管了，你越管他越不来。思者的娃，我不劝你，你自己看，觉得有用就留下，没用就走。选择权在你手里——但你得先来看一眼，才能判断。」

## 5. 顾问 / 智能体红线

- 必须 **第三方介入**；禁止让德者妈妈继续当面硬劝
- 对孩子：平等信息 + 选择权；禁止「替妈妈完成说服」姿态
- 给妈妈：确定性（方法、专业、退费规则），而非「怎么继续说服」
- 不因「已交费」压迫孩子；「放手」说成策略不是放弃
- 禁止具体提分承诺
