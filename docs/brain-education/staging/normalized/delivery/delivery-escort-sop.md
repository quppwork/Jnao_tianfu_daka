## 一、定位与目标

### 1.1 部门定位

- 交付 / 护航团队掌握公司**最核心的导师与客户资源**，属不可替代中枢部门
- 管理逻辑：**高薪 + 严管** —— 底薪可量化、过程可查，才配得上高激励
- 管理目标不是「追最高」，而是**守住底线**：敷衍者混不下去，用心者有回报

### 1.2 核心指标（会议口径）

| 指标 | 现状 / 目标 |
|------|-------------|
| 导师用户满意度 | 约不足 30% → **目标 60%** |
| 新导师六步交付周期 | **30–60 天内完成**（禁止拖到四五个月） |
| 客户自主运行 | 约 **60 天内**降低对高频人工依赖 |
| 单老师服务容量 | 约 **60–70 个群** / 人可稳定维护 |

## 二、六步交付体系（新导师护航）

针对新导师，以月为节奏设 **A–F 六个关键服务节点**；每完成一步＝一次有效跟进；**六步全部完成**＝一次「有效交付」（奖金核算单位）。

### 2.1 节点节奏（建议）

| 组 / 节点 | 时间窗 | 服务重点 |
|-----------|--------|----------|
| **A** | 当日建联 | 海报+自我介绍、建群、首通、7 天目标规划 |
| **B** | 第 7 天 | 首周复盘、卡点排查、打卡习惯固化 |
| **C** | 第 8–13 天 | 能力推进、家长陪伴认知强化 |
| **D** | 约第 14 天 | 深度沟通、方案调整 |
| **E** | 约第 21 天 | 阶段验收、自主性检查 |
| **F** | 约第 30 天 / 收口 | 六步闭环、转答疑为主或有效交付认定 |

> 前 **30 天**＝重点跟进期；之后以答疑为主。整体宜在 **30–60 天**内完成六步。

### 2.2 服务内容主线（围绕超脑九段）

1. **建立家长陪伴认知**（陪伴 ≠ 单纯盯人）
2. **技术掌握**：超脑阅读、影像追忆、扫描速记等（按九段递进；极速学习常在火箭营后介入）
3. **日常坚持训练** + 打卡（音频前/后数据）
4. **定期深度沟通**：首次建联 → 7 / 14 / 21 天 → 每月跟进

### 2.3 前 7 天「启动期」必做动作（最低集）

- [ ] 首次电话（建议语音/电话，单次可到约 45 分钟量级谈双线卡点）
- [ ] 发送基础课：《读懂爱的语言》《能力训练三要素》等
- [ ] 制定初级音频训练方案
- [ ] 指导打卡：生成打卡图、进群打卡、每日数据填写
- [ ] 未打卡 → **立即电话**排查卡点
- [ ] 规划清晰的 **7 天训练目标**

### 2.4 分步推进铁律（反信息堆砌）

```
先教一项 → 实践 → 反馈 → 再教下一项
```

- **禁止**：一次发十几二十条资料把家长淹没
- **提倡**：先语音梳理节奏，再发对应资料；像「恋爱节奏」控制感受与密度
- 资料发到**交付群** + **电话告知**「我给你发了特别有用的资料」（可提醒 3–5 次）
- **不推荐**单独建「资料存储群」为主路径（家长不看、易被竞品批量拿走）

## 三、响应时效与工作纪律（SLA）

| 场景 | 标准 | 备注 |
|------|------|------|
| 新客户建联 | **10–20 分钟内**发个人海报 + 简短自我介绍 | 专职专岗，超时不允许 |
| 老客户提问 | **半小时内**必须响应 | 忙时先回「稍后回复」 |
| 工作监察时段 | 每天 **9:30–22:30** | 此时段外可不计入监察 |
| 中午休息 | 约 12:00–13:30 | 允许适度延迟 |
| 22:30 后 | 可不回复、不纳监察 | 建议酌情提升满意度 |

## 四、服务温度标准（反「机器人感」）

会议核心矛盾之一：家长觉得服务「像机器人」。统一要求：

1. **语音优先于纯文字**（传情绪与安全感）；关键标准 / 流程仍用文字确认防遗漏
2. 增加问候与轻度表情（如「某某家长晚上好」），提升交互感
3. 回复前先平复自身情绪，禁止僵硬 / 不耐烦口吻
4. 节假日体现人文关怀，**禁止**只会催「加强训练」
5. 护航本质是**要跟客户亲近**，不是「能干一半就干一半」、怕被打扰
6. 保持专业，反对过度卑微；目标是客户感到被重视，甚至「连退款都不好意思」

## 五、服务留痕与数据系统

### 5.1 两大核心表

| 表 | 用途 |
|----|------|
| **总部护航数据跟进表** | 每位客户完整轨迹：建联截图、总结反馈、打卡提醒、答疑沟通等 |
| **交付老师日报表** | 日汇总：新客建联数、总打卡人数、未打卡人数、家长答疑情况等 |

两表数据需可互相匹配，接受管理层随机抽查。智能表支持：微信关联、标签同步、7 天节点预警、按交付老师筛选。

### 5.2 沟通闭环模板（三点总结）

每次有效沟通后必须写三点，并请客户回复满意度：

```
1. 我解决了什么问题：
2. 提供了什么方案：
3. 请您回复是否满意：（满意 / 不满意）
```

- 客户回复「满意」后，将**整段对话截图**（含时间戳）上传跟进表
- 未闭环不算有效服务留痕

### 5.3 企业微信标签（必打）

至少包含：

- 客户来源
- 孩子属性（年级 / 天赋等）
- 家长属性
- 参与期数

电话录入「备注和描述」中的电话字段，便于同步主表。

### 5.4 客户变更规范

| 情况 | 做法 |
|------|------|
| 信息重复 | 确认后合并，删冗余 |
| 客户转移 | **禁止直接删除**；备注「已转交 XXX + 日期」，必要时附截图 |
| 导师升级为合伙人/店铺 | 原交付老师不必继续跟；系统标注变更，移交对应负责人 |

## 六、通关考核与值班答疑

### 6.1 护航老师通关考核（上岗前提）

参照销转「通关」思路，护航须通关后再独立值班。通关至少包含：

1. 各项目**怎么练**（超脑阅读、影像追忆、扫描速记等）
2. **孩子常见卡点**
3. **家长常见卡点**
4. **引导话术框架**（允许风格差异，禁止本质偏差）

底座标准：**超脑九段训练标准** + 图文材料（见 [training.md](../training/methods.md)）。

### 6.2 百问百答 + 话术库

- 以现有「百问百答」表为底，早课答疑持续补题
- 学习有温度的客服话术：节日问候、日常关怀语料
- 目标：任何人值班，答案一致

### 6.3 每日值班答疑

| 项 | 说明 |
|----|------|
| 参照 | 火箭提分营早晚答疑 |
| 定位 | **纯训练实操卡点**解答（区别于家长课堂的知识+情感） |
| 时段建议 | 约晚上 **9:30 后**（家长空闲高峰） |
| 前提 | **标准必须先统一**，否则「你这样说、他那样说」 |

让每位家长清楚：**此刻有问题可以找谁**。

### 6.4 质检机制

- 管理者对负面体验默认归因：「是我的事」；即使客户有责，也要想如何让对方意识到
- 抽查通话记录；**亲自听**每位成员前 **3–5 通**关键电话（首通、阶段回访等）
- 可用双设备同步监听做质检

## 七、资料库与教研

### 7.1 核心交付资料库

- 按 **学段 / 学科 / 天赋属性** 分类，加小标题与标签，全员可调取
- **精准推送**，考试季主动发作文、升学复习包等实用内容
- 与经销商服务部**共享客户数据表**（孩子情况、需求、家长进度、服务记录）

### 7.2 教学研究院（方向）

- 定位：深度交付教研中心（护航专家 + 学科教师）
- 课题示例：如何用影像追忆提升文言文背诵效率
- 鼓励一线反向优化早课：「哪里可以改」→ 案例库迭代
- 反对服务长期无进化导致链接变浅

### 7.3 专项延伸（备忘）

清北班专项、教辅筛选 / 购书平台、试卷资源整合等——增强「训练 → 学科成果」闭环，细则另案。

## 八、体验客户接入（简流程）

```
推荐导师发起 → 建群 → 天赋测试 → 收集详细资料 → 分配护航老师
```

掉队 / 长期沉默客户需有唤醒策略；历史不满客户可移交标准护航团队统一标准。

## 九、激励与容量（会议口径，引用时注意边界）

| 项 | 口径 |
|----|------|
| 胜任者底薪 | 约 12,000–15,000 元/月（不含奖金），前提是可量化、有检查 |
| 有效交付奖金 | 每完成 1 名新导师六步交付单独计奖；量多排名高则奖更高 |
| 容量粗算 | 1 人约 60–70 群；8 人约 480；按两月一批迭代，年承载量级可达数千导师客户 |

经营推演数字仅供内部规划，对外不作承诺。
