## 一、总原则

### 1.1 输入与输出必须组合

所有能力分两大维度，**不能单靠一项**：

| 维度 | 含义 | 代表能力 |
|------|------|----------|
| **输入（存储）** | 吃进去 | 超脑阅读、扫描速记、多元感知 |
| **输出（调取）** | 拿出来用 | 影像追忆、极速运算、三错一讲 |
| **综合** | 存取合体 | 极速学习 |
| **应用** | 场景化 | 无界外语、学科奥秘、直觉决策 |

### 1.2 学习问题三问

解决孩子学习，常落到三点：**态度、能力、方法**（见 [theory.md](../foundations/theory.md)）。

### 1.3 通用训练形态

1. 戴耳机 + 眼罩（部分项目）
2. 听**按天赋匹配**的定制音频
3. **立刻验收**（字数 / 复述率 / 正确率）
4. 迁移到课本 / 作业真实场景

家长原则：不批评打压；平和喜悦时练；可用比赛形式；一次不达标鼓励再来。

## 二、九项能力详解（神功对照）

| 代号 | 能力 | 神功名 | 核心 | 学科 | 训练要点 |
|------|------|--------|------|------|----------|
| A | **高效作业** | 呼吸打坐（入门桩） | 声波屏障抗干扰，静心专注 | 全科 | 构建抗干扰状态，进专注 |
| B | **超脑阅读** | 左右互搏 | 开口窍：左右脑同步，效率翻倍 | 全科（文尤佳） | 出声快读 / 不出声扫读 + 音频 |
| C | **影像追忆** | 小无相功 | 所见所闻随时调取复述，活学活用 | 文为主，全科可用 | 复述、再现、细节整合 |
| D | **扫描速记** | 吸星大法 | 逻辑记忆→图像记忆；年龄越小越好练 | 全科 | 不分析地图像化吞信息 |
| E | **三错一讲** | 独孤九剑 | 讲透错题考点，见招拆招 | 压轴 / 简答 / 阅读 | 一天前/一周前/两周前各讲一题 |
| F | **极速学习** | 葵花宝典 | 速度优先；信大脑真实反应 | 全科 | 限时、高频，破慢逻辑惯性 |
| G | **极速运算** | 太极神功 | 化繁为简，调取潜能运算 | 理为主 | 年龄越大越难；提炼规律 |
| H | **多元感知** | 六脉神剑 | 多感官联动，扩「硬盘」 | 潜能 | 蒙眼辨色辨形等；易争议，需边界 |
| S | **无界外语** | 九阴真经 | 多能力贯通，母语式习得 | 外语 | 整合速记速忆，绕开死背 |

### 2.1 存储 vs 调取（再强调）

- 超脑阅读 + 影像追忆 ≈ **仓储 + 取货**
- 扫描速记 ≈ 不思考的快速入库
- 只会「照相机式」记下考完就忘 → 缺的是**忆（调取运用）**，不是只会拍

### 2.2 与应试坏习惯对照

| 坏习惯 | 破解能力 |
|--------|----------|
| 只会读不会记 | 超脑阅读 |
| 只会记不会用 | 影像追忆 |
| 坐不住 | 高效作业 / 专注 + 感知 |
| 运算慢 | 极速运算 |
| 学得慢 | 极速学习 |
| 外语死背崩溃 | 无界外语 |

## 三、超脑阅读：原理与操作（基础入门课）

### 3.1 原理

- 打开大脑潜能的**最基础一环**，其它训练的入门
- 左脑管语言表达；大声读＝左脑输出给右脑听与存
- 关键不是「读了多少」，而是**怎么读、练什么能力**
- 口诀：**一目十行（专注快速）· 观其大略（掌握精髓）· 不求甚解（抓住要害）**

### 3.2 方法一：出声快读

1. 选孩子喜欢的文字书（少图；避开漫画绘本）
2. **最大声、最清晰、最快**读 5 分钟，计时记字数
3. 听【超脑阅读】音频
4. 再大声读 5 分钟，对比字数打卡

要点：加速；不指读、不回读；错字生字**跳过继续**。

### 3.3 方法二：不出声快扫

同上结构，但用眼睛快速扫书（快快快），音频前后各 5 分钟对比。

### 3.4 开口窍（随时练）

- 以 1 分钟为单位：出声、快速、加速
- **眼睛走在嘴巴前面**，眼领嘴跑
- 可穿插在其它训练间隙

### 3.5 参考目标（字/分钟）

| 学段 | 入门目标（素材口径） |
|------|----------------------|
| 小学 | ≥1000 |
| 初中 | ≥1500 |
| 高中 | ≥2000 |

不识字幼儿：暂缓超脑阅读，先做其它训练；识字少则并行识字。

## 五、超脑九段（段位体系）

> 每一段有训练内容 + **可量化晋级线**；达标才升级。
> 剧中可视化可用「光塔九层」；教育交付用同一套标准。

### 5.1 九段内容地图

| 段 | 定位 | 核心新增 / 重点 |
|----|------|-----------------|
| **一段** | 入门，效率 1–3 倍 | 高效作业、超脑阅读、影像追忆 |
| **二段** | 能力觉醒，抗遗忘 | 超脑阅读、影像追忆、扫描速记 |
| **三段** | 开窍攻难题 | 影像追忆、扫描速记、**极速运算** |
| **四段** | 火箭提分营门槛 | **极速学习** + 前序能力综合 |
| **五段** | 学科底层 | 文科奥秘、理科奥秘 + 综合能力 |
| **六段** | 全脑素质 | 天赋绘画、音乐灵感 |
| **七段** | 学习高手 | 化繁为简、思维导图（门内弟子门槛） |
| **八段** | 语言与人生设计 | 母语特训、人生规划（关门弟子向） |
| **九段** | 最高阶 | 专利精英、无界外语、干扰训练 |

### 5.2 一段晋级要点（摘要）

**高效作业提速**（无「二段」晋级，只作基础能力）：

| 学段 | 普通 | 优秀 | 大神 |
|------|------|------|------|
| 1–3 年级 | ≥30% | ≥45% | ≥60% |
| 4–6 年级 | ≥25% | ≥35% | ≥50% |
| 初中 | ≥20% | ≥30% | ≥45% |
| 高中 | ≥15% | ≥25% | ≥40% |

**一段 · 超脑阅读 + 影像追忆（示例）**：

| 学段 | 超脑阅读 | 影像追忆 |
|------|----------|----------|
| 1–3 年级 | 1 分钟 800 字 | 读 1500 字以上，复述核心准确度 75% |
| 4–6 年级 | 1 分钟 1000 字 | 3–4 分钟看完 3000 字+，准确度 75% |
| 初中 | 1 分钟 1800 字 | 4–5 分钟看完 5000 字+，准确度 80% |
| 高中 | 1 分钟 2000 字 | 5–6 分钟看完 6000 字+，准确度 80% |

### 5.3 二段起（扫描速记加入）

二段起要求扫描速记「1 分钟 N 字精准记忆，可抽查倒背」；学段越高，阅读目标字数升、速记字数标准按表调整（小学低段字数要求可高于高中——因材料难度与训练侧重不同）。
**完整分学段数字表**以训练运营现行表为准；本库已收录素材版一至四段主干，五段及以上以作品打卡 / 面试申请为主。

### 5.4 四段与火箭提分营

- 须具备前三阶段基础，才谈全脑学习能力
- 五天营：素材口径为效率 3–10 倍或总分 50–100 分（**需独立核实**）
- 营后必须持续影像追忆、超脑阅读等实战技巧，否则回落

### 5.5 七至九段门槛性质

- 七段：门内弟子，能力达标后申请面试
- 八/九段：关门弟子向；九段含专利与商业策划、多语自学技巧、强干扰下自信等

### 8.0 总则：什么叫「脑力提升」

| 要点 | 书中口径 |
|------|----------|
| **定义** | 意识对潜意识的控制更精准，正向通路更顺畅 |
| **输入端口** | 五感；学习上首选**视觉**，其次**听觉**；未来可延展触/嗅等 |
| **内容预设** | 视觉/听觉输入内容须预设（训练师或设备） |
| **有效频次** | 决定提升幅度与速度 |
| **三阶段** | ① 高速存储（扫描速记 / 影像追忆）→ ② 精准控制（极速运算）→ ③ 学习快乐（极速学习） |

与九项能力表（本文 §二）关系：本章是书中「方法原理」轴；超脑阅读等演讲课能力与之配套，勿混成两套互斥体系。

### 8.1 记忆的本质：记与忆

| 步骤 | 含义 |
|------|------|
| **记** | 五感输入（见/听/经历体验）；**不含**理解分析；书面「背书」只是狭义场景 |
| **忆** | 全部在脑内：回放经历 = 执行「调取」指令 |

- 记是本能：内心**不抗拒**则可自然输入
- 短 / 长期记忆差别主要在**忆的速度（调取难度）**
- 愉悦或反复使用 → 易入长期记忆（机制交叉见 [learning-methods.md](../practice/learning-methods.md) 两日三记 / LTP）
- 超出短期时效又未入长期 → 被「雪藏」

**脑力训练真正打的两块**：

1. **扫描速记** → 短期记忆的效率（速度与量级）
2. **影像追忆** → 对「短期已丢、长期未进」的**指向性调取**

验收常伴随输出：写出 / 说出 / 画出。记忆力本能应用意义有限；提升的是**基础知识输入周期与量**，为系统学用备料。

---

### 8.2 扫描速记（图像 / 照相机记忆）

| 项 | 要点 |
|----|------|
| **定位** | 应对平面书面记忆；视觉是最有效窗口 |
| **与其它记法区别** | 不是联想记忆、理解记忆；**记与忆严格分开** |
| **记** | 切断思考，快速扫描；文字也当**字形图画**，以图像为单位输入 |
| **忆** | 扫描后复原重构画面，再读出 / 写出 |
| **训练** | 扫描速记音频 + 脑视镜锁定清晰度看影片；**当场检验** |

**曾有图像记忆体验者**：易误以为「天生、长大必退」→ 信心与使用频率下降 → 能力真退。训练恢复往往比「从未体验者」更快。交付时纠正负面信念。

---

### 8.3 影像追忆（扫描速记的双生 · 重「忆」）

| 项 | 要点 |
|----|------|
| **定位** | 对短期丢失、未入长期部分的**指向性抓取**；场景化重建，非单字回放 |
| **价值** | 短时唤醒课堂/笔记/书本，少做无效重温；成就感强 |
| **要求** | 局部重塑选择性遗忘机制；**配合度要求高** |
| **工具** | 影像追忆音频（左右耳不同声道）+ 脑视镜 → 超三维体验叙事 |

**稳定性风险（必讲）**：心智未成熟 + 学业挫折 + 家校压力 → 凡「跟学习有关」的训练都可能降愉悦、生反感。即便扫记已会，讨厌科目仍可能被潜意识**选择性遗忘**。

化解：

1. 用五者工具加强沟通与认同、自主与梦想（见 [talents-application.md](../practice/talents-application.md)）
2. 先进工具辅助体验（脑视镜：红蓝三维动画 + 插播立体文字记忆 → 唤醒三级视力、提娱乐性、多线程做潜意识引导与意愿提升）

### 8.4 视力修复（眼脑配合 · 非替代就医）

| 红线 | 说明 |
|------|------|
| 病理性 / 器质性眼病、发育问题 | **及时就医**；与脑力训练无直接因果，可互补不冲突 |
| 本章提升对象 | 含视神经在内的**大脑图像处理**整体视力功能 |
| 医院趋势（书中） | 眼科与神经内科协同；眼脑配合训练逐步普及 |

#### 8.4.1 第一部分：眼脑配合（变焦白片）

- 模糊图出现 → 大脑自动「清晰化」；强度 ∝ 脑力 + **想看清的意愿**
- 意识给潜意识「变清楚」指令 → 潜意识执行；依赖左右脑配合
- 清晰↔模糊反复切换 → 频繁执行指令直至内化 → 刺激视觉功能区
- 变焦白片自适配速度，一般由慢到快
- **物理侧**：刺激睫状肌收放（晶状体调焦「跑步机」）
  - 久看近 → 睫状肌痉挛难放松 ≈ 近视叙事
  - 年长肌无力、难调近 ≈ 老花叙事

注（书中澄清）：眼轴 = 角膜到视网膜距离；晶状体焦距 = 光学焦长 —— **都不是**某个可单独「摸到」的构件名。

#### 8.4.2 第二部分：加强第三视力（变焦红蓝片）

- 第三视力：大脑渲染、关联、补图（见 [theory.md](../foundations/theory.md) 三级视力）
- 红蓝镜片提供双眼不同图像 → 大脑合成立体 → 高阶图像处理 + 助内视力 → 反哺扫描速记等

#### 8.4.3 适用性（书中口径 · 需核实效果数据）

| 情况 | 书中 |
|------|------|
| 近视 / 远视（焦点在视网膜前/后） | 白片 + 红蓝片均有效叙事 |
| 散光（视轴弯曲偏离） | 睫状肌训练作用不明显 → **红蓝片**有效叙事 |
| 戴镜 / 曾激光手术、基本正常眼 | 可有不同程度提升叙事 |
| 角膜 | 不因本训练改变 |

设备让训练减枯燥、提成效——与 [technology.md](../frontline/technology.md) 交叉。

### 8.5 极速运算（灵感链接 · 不是奥数速算班）

| 项 | 要点 |
|----|------|
| **本质** | 左右脑互链；潜意识对意识「开放指令」**直接给结论**的响应练习 ≈「灵感来袭」 |
| **条件** | 稳定自信 + 高度专注的 **α** 态 |
| **为何用数字** | 足够简单、基础积累最少；条件简化为专注与自信 |
| **进阶** | 树突轴突链接变丰富 → 灵感可更复杂；高阶升级为**刷卷**（内训带课） |

书中例：舒伯特读诗灵感来袭、菜单五线谱记《听云雀》——兴趣沉浸 → 易入 α → 打通意识与潜意识。灵感可为数字/画面/旋律/剧本/答案。

交付：练的是**信任潜意识回应 + 抓取**，不是教珠算口诀。

### 8.6 极速学习（综合应用）

| 项 | 要点 |
|----|------|
| **定位** | 以上单项的综合；直觉决策 / 第二信号系统的高阶检验 |
| **元认知** | 「学习方法」本身也要学与练；工欲善其事必先利其器 |
| **刷卷融合** | 扫记现学 + 影像追忆调旧知 + 未学但可推知内容融合 + 极速运算给反应 → 综合出答案 |

**给潜意识「施工」的辅助（书中）**：

1. 不断输入常识 / 专业 / 成功相关信息（事事留心皆学问）
2. 重要资料重复；建看得见的资料库（书报笔记电脑等）协助创造
3. 珍惜积极因素，让积极成功心态占优，成直觉习惯
4. 把梦想与难题化成清晰指令交给潜意识，放松等待答案
5. 灵感随时记（纸笔 / 备忘）；自我暗示与确认要**反复**
6. 天赋自我认知 + 独立人格强化后，调动速记/追忆/速算/刷卷 → 与智慧正相关；书称同步利于心理问题（**不作医疗承诺**）

**潜意识三重境界**（与 theory 一致）：

| 境界 | 状态 |
|------|------|
| 大众智慧 | 困惑不解又无能为力 |
| 高手智慧 | 化繁为简又高效灵活 |
| 圣贤智慧 | 无限可能又为我所用 |

良性循环：输入 → 运用 → 更多知识诉求 → 再习得。

### 8.7 催眠专章（索引 · 交付边界）

> 原书第九章含较长催眠论述。本库**只收概念地图与红线**，不提供可操作诱导脚本；未成年人相关须持证 / 内训资质人员执行。

| 概念 | 一句话 |
|------|--------|
| **催眠是什么（书中）** | 专注到极致、放弃抵抗；精神力如激光；潜意识门开，指令易被「当真」 |
| **心锚** | 在高专注态种下「我是坚强/有爱/成功的人」等指令，坎坷时反复调用 |
| **可唤醒记忆** | 经历未消失，常是找不到；专注强则可调（叙事；非医疗承诺） |
| **信念强植** | 用最深渴望突破自我保护与旧信念；环境可见处反复写信念（与目标视觉化同源） |
| **意识演练** | 意念练习可强化表现（书引哈佛飞镖等——**需核实**）；可迁移到快速印书、一目十行叙事 |
| **唯一门户** | **专注力**打开潜意识；门开越大进得越多；干扰中练专注 = 绑沙袋跑步 |

**三重催眠类型（书中点名）**：主动 / 被动；深度 / 浅度；另有「强植性催眠」。

**交付红线**：

1. 一线勿自行给人「催眠治病 / 改性格」
2. 恐怖片隐喻只说明潜意识不分真假，勿恐吓孩子
3. 「潜意识是意识 100 万倍」= 教学数量级，勿当实验数据
4. 与第一章一致：触碰潜意识要有**正向意识前提**；未成年人有年龄边界

## 八附、大会训练增量（转写甄选 · 2026-08）

> 来源：0816–0817 杭州等场次。与 §八 书中方法互补；**安全异常仍以 §九 为准**。

### 附.1 能力训练进程（金字塔）

```
开口窍 / 超脑阅读（左右脑同步）
        ↓
影像追忆（调取）+ 专注续航
        ↓
扫描速记（图像存储 · 名门未稳勿先猛练）
        ↓
极速运算 + 直觉决策
        ↓
极速学习（综合刷卷）→ 再叠文/理/外语
```

- 扫记像「吸星」：考前有、考完空、不理解 → **基础未稳勿先练**
- 单练极速学习「提分到顶再叠学科」属演讲叙事，须核实

### 附.2 感知力带训（方法摘要 · 禁作弊）

| 步骤 | 要点 |
|------|------|
| 遮光 | **完全遮光**才有效；透光/偷看无效；用舒适 3D 眼罩，勿压伤眼球 |
| 触觉 | 拇搓牌面正反（滑/糙） |
| 近脑 | 牌可贴额等（电磁波「近」叙事，作教具） |
| 嗅 / 唇触 | 轻闻、唇触开敏感；**禁止伸舌**（已淘汰） |
| 颜色校准 | 报错时告知正确色名，记住「该频率≈该色」；黄绿易混 |
| 形状 | 指沿轮廓；先色或先形择敏入口 |
| 剂量 | **够用即止**；过度有考场公平争议风险 |
| 关系 | 亲子关系差难练；可换人带，勿否定「没能力」 |

**红线**：禁止写可复现的「读邻桌/作弊」细节；禁止神化超能力；高敏感立刻停感知类（见 §9.1.2）。
副作用叙事：累、需休息与营养补充——**非医疗诊断**。

### 附.3 盲视力安全前提

- 完全遮光模拟；器材优先不碰眼球的眼罩
- 定位：**低阶代偿觉醒**，非超级英雄

### 附.4 波动导读 / 波动导图

| 项 | 要点 |
|----|------|
| 谱系叙事 | 七田真系「量子波动速读」；单能力效果有限，须叠追忆/超脑阅读/刷题 |
| 两种翻法 | 蒙眼扇书（感知强）；睁眼左右快扫（扫记强） |
| 带训 | 耳机+偏暗环境 → 翻书 → **立刻画导图/向家长讲** |
| 「量子」 | 勿伪科学硬证；单训勿承诺提分 |

### 附.5 心灵感应（争议 / 演示项）

- 现场常为：孩戴眼罩、家长握手想画面让孩子说
- 入库表述：亲子专注与非语言互动练习，**效果因人而异**
- **勿当超自然教学对外承诺**；勿替代心理咨询

### 附.6 工厂隐喻（口播）

扩建库房（感知）→ 修高速（通路）→ 自动化（直觉决策）——与分型训练序同讲。
