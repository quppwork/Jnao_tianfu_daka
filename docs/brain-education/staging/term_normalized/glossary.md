## 口径摘要（与裁定纪要对齐）

1. 「最不喜欢学」金句主体是 **思者**（监管：规矩+条件约束）；学者侧重赏识。  
2. 爱上学习链路可并存两套表述（家长向 / 交付向）。  
3. 行者画像保留双面，按副属性选用。  
4. 宣传数据、提分数字须核实；禁止具体提分承诺。  
5. 医疗 / 极端心理问题转专业人士。

- 仅对正文中误用为五者名的搭配、以及「开口穹」「阿尔法*」「8-13 Hz」连字符等做归一。
