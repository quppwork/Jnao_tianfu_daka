## 二、六步交付体系（新导师护航）
针对新导师，以月为节奏设 **A–F 六个关键服务节点**；每完成一步＝一次有效跟进；**六步全部完成**＝一次「有效交付」（奖金核算单位）。
### 2.1 节点节奏（建议）
| 组 / 节点 | 时间窗 | 服务重点 |
|-----------|--------|----------|
| **A** | 当日建联 | 海报+自我介绍、建群、首通、7 天目标规划 |
| **B** | 第 7 天 | 首周复盘、卡点排查、打卡习惯固化 |
| **C** | 第 8–13 天 | 能力推进、家长陪伴认知强化 |
| **D** | 约第 14 天 | 深度沟通、方案调整 |
| **E** | 约第 21 天 | 阶段验收、自主性检查 |
| **F** | 约第 30 天 / 收口 | 六步闭环、转答疑为主或有效交付认定 |

> 前 **30 天**＝重点跟进期；之后以答疑为主。整体宜在 **30–60 天**内完成六步。
### 2.2 服务内容主线（围绕超脑九段）
1. **建立家长陪伴认知**（陪伴 ≠ 单纯盯人）
2. **技术掌握**：超脑阅读、影像追忆、扫描速记等（按九段递进；极速学习常在火箭营后介入）
3. **日常坚持训练** + 打卡（音频前/后数据）
4. **定期深度沟通**：首次建联 → 7 / 14 / 21 天 → 每月跟进
### 2.3 前 7 天「启动期」必做动作（最低集）
- [ ] 首次电话（建议语音/电话，单次可到约 45 分钟量级谈双线卡点）
- [ ] 发送基础课：《读懂爱的语言》《能力训练三要素》等
- [ ] 制定初级音频训练方案
- [ ] 指导打卡：生成打卡图、进群打卡、每日数据填写
- [ ] 未打卡 → **立即电话**排查卡点
- [ ] 规划清晰的 **7 天训练目标**
