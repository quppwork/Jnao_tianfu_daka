### 5.5 学者孩子
**学习特质（书中）**：主动学、自尊敏感、逻辑清晰、缺乏应变；超能力是一心多用；学不好常因自尊受挫。
**核心解法**：赏识 + 规划 + 干扰中练专注；信任其自觉自律。

- 伤自尊 → 易厌学偏科；问题点到为止留面子
- 故意加一点「干扰 / 不完美」训练，防刻板
- 少用「别人都可以你为什么不行」；问问题就给资料（孺子可教）

**家长气头上，学者内心戏（书中）**：委屈内疚、觉得自己也想做得更好 → 气消后会拿出表现，信任即可。
### 5.6 左右脑家长沟通总则（《超脑进化之书》）
> 科学底盘（割裂脑 / 单侧化 / 为何分左右脑型）见 [theory.md](../foundations/theory.md) §四；脑型→者型光谱见 [talents.md](../foundations/talents.md) §〇。
> 亲子**同属性 / 相生 / 相克**时「爱」的三种变形（纵容·伤害·无奈）见 [learning-methods.md](learning-methods.md) §0.6。

| 孩子脑型 | 沟通要点 |
|----------|----------|
| **右脑**（思 / 赢） | 少讲歪理式说教，**规矩**更有力；有事可忙 / 有「赚」；家务耗体力，学习时专注才够；赏罚要严格执行 |
| **左脑**（德 / 行） | **讲道理 + 陪伴监督**；多开口说、多做主；多关爱不怯懦；**绝对避免体罚**（胆小记仇） |
| **平衡**（学者） | 赏识第一；点到为止留面子；「你真棒」往往够用 |
