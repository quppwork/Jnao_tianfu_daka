## 一、第七章总览：天赋学习力与学习方法（精读）
> 对应书：**七、天赋学习力和学习方法**
> 结构：学习力分析（五者特质 · 家庭组合 · 家长五级）→ 学习方法（两日三记 · 三错一讲 · 学业规划 · 综合流程 · 考前）。
> 亲子内心戏 / 带法话术交叉见 [talents-application.md](talents-application.md) §5。
### 1.1 开篇定位
| 概念 | 书中口径 |
|------|----------|
| **总方针** | 每个孩子都是冠军；天赋不同 → **赛道不同** |
| **道 vs 术** | 学习**规律**是道；学习**方法**是术 |
| **三管齐下** | 提升大脑能力 · 改善学习态度 · 赋予提分方法 |
| **植入逻辑** | 学科规律高度总结 → 潜意识引导；短板用「相反暗示」逆转习惯；精准正面激励植入**心锚** |
| **结果观** | 提的不只是分数，更是人生选择权与精彩可能 |

```
学习力 = 态度 + 方法 + 能力
```

**金句**：顺应天赋因材施教，所有的孩子终成学霸。
### 1.2 左右脑学习总策略（分析开篇）
| 脑型 | 学习痛点 | 带法优先 |
|------|----------|----------|
| **左脑**（德 / 行） | 理解偏慢；练得多未必掌握；记不快 | **讲懂确认 > 盲目重复**；德者可推着学、持续增压；行者先疏通情绪再讲；多开口说 |
| **右脑**（思 / 赢） | 忘得快、答题「会的也错」；边学边玩效率低 | 先解决**目标 / 意义 / 梦想**态度；赢者奖励机制；思者梦想+榜样+优越感；自学要有明确动力 |

双减语境（书中）：时间已经够多 → 有效减负是提升意义与按天赋挖潜力，不是再堆时长。
