## 三、学习丢分根源（文 / 理 / 外）
| 天赋 | 常见丢分表现 |
|------|----------------|
| 思者 | 阅读慢像打字机、理解力差（厌学时） |
| 赢者 | 阅读快但粗心马虎 |
| 德者 | 解题力差、缺抽象思维、白刷题 |
| 行者 | 死记硬背不会运用、大题丢分多 |
| 学者 | 平时不背课、考完就忘；外语平时不讲则学不透 |

辅导时：先对上「丢分类型」，再选训练能力（见 [training.md](../training/methods.md)），避免盲目加作业量。
