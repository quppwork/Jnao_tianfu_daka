### 0.3 同一技能，五套学习顺序（绘画例 → 通用）
书中以绘画为例：**先本道找成就感，再相生，后相克**。可迁移到其它技能设计。

| 者型 | 第 1 步（本道） | 第 2 步（相生邻） | 第 3 步（相克 / 补短） |
|------|-----------------|-------------------|------------------------|
| **思者** | 创意（创新尝试） | 技巧（赢） | 功底（行） |
| **赢者** | 技巧（好表现、见成果） | 感觉（德） | 临摹补创意不足 |
| **德者** | 感觉（色彩/空间） | 功底（行） | 创意（思） |
| **行者** | 功底（扎实执着） | 临摹 | 技巧（赢）→ 自成风格 |
| **学者** | 临摹（快速学习） | 创意（思） | 感觉（德）→ 融入情感 |

顾问口诀：**成就感开口 → 相邻加持 → 相克补短**。
### 0.4 五力个性化训练顺序（复制期）
在「观察→专注→创造→想象→记忆」总通路之上，书中又给出**按本道优先**的打开顺序：

| 者型 | 训练顺序（书中） |
|------|------------------|
| 思者 | 创造 → 想象 → 记忆 |
| 赢者 | 想象 → 观察 → 专注 |
| 德者 | 观察 → 记忆 → 创造 |
| 行者 | 记忆 → 专注 → 想象 |
| 学者 | 专注 → 创造 → 观察 |

亦可五力按总序同时推进，但仍**加重本道**（与帐篷「最高柱」隐喻一致，见 theory §七 / 下文）。
