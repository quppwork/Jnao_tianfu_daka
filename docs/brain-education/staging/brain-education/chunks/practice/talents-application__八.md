## 八、服务老师 / 顾问话术结构（建议）
一次家长沟通可按四步：

1. **定型**：孩子更像哪一者（行为证据 3 条；可对照「最怕」清单）
2. **翻案**：用「误解标签 → 真相句」降低对抗
3. **诊断**：丢分类型 + 态度/能力/方法哪块缺；可对照学习力五维分
4. **处方**（教学类比，非医疗处方）：培养口诀 + 1～2 个训练能力 + 家长最小动作

禁止：用另一天赋的标准羞辱孩子（如逼思者「像行者一样坐得住」当唯一美德）。
