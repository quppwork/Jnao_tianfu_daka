### 0.5 潜能「帐篷五柱」与递减法则
- 五柱 = 创造 / 想象 / 观察 / 记忆 / 专注；出生时一根最高最粗 = **本道**
- 先用好最高柱 → 带动其它柱长高 → 大脑「容量」扩充
- **递减法则（书中）**：越晚教育，浪费越多（五岁左右教可激发大半；十岁后即使方法好也大打折扣——**教学叙事，需核实**）
- 狼孩等例：错过语言关键期难补 —— 强调窗口，**非恐吓家长**

五觉对应（与第四章一致）：思视 / 赢味 / 德触 / 行嗅 / 学听。
### 0.6 亲子属性：三种「爱」的变形
| 亲子关系 | 爱容易变成 | 机制（书中） |
|----------|------------|--------------|
| **同属性** | **纵容** | 优点一致；缺点自己看不见，也漠视孩子同款缺点 |
| **相生** | **伤害** | 用自己标准要求孩子（例：赢父母催思孩子要目标要快） |
| **相克** | **无奈** | 你要的刚好是孩子缺的（例：学父母严管德孩子要的是宽容情感） |

**处方总则**：先定位，再分析，后指导 ≈ 诊断 → 病理 → 处方（**教学类比，非医疗处方**，指「定位问题 → 分析原因 → 给出指导」）。
欣赏最闪耀的那一力；给空间与互动语言——否则沟通只剩「挺好、随便、还行」。
