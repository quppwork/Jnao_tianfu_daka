### 8.1 为何练「复杂处理」
书中：真正想要的是处理复杂知识 / 复杂工作的能力（重工业研发、桥梁、医药、航空航天等叙事）→ **面对复杂事物的学习力与创造力 = 核心生产力**。

布鲁纳（书中引）：无结构组织的知识易忘；按原理观念组织论据，是降低遗忘的已知方法。
### 8.2 最小循环
```
输入 → 检索 → 输出 → 应用场景扩大 → 更多输入需求
最小单元 ≈ 快速习题（极速学习）
```

右脑 ≈ 硬盘 + CPU；左脑 ≈ 搜索引擎；检索次数↑ → 匹配更准更快。
### 8.3 综合学习方法流程（有基础脑力训练后）
1. 整理学期科目与教材、习题、试卷
2. 科目清单：近期分 + 目标分
3. 刷卷计划表（**行者：不在量大，在知识点全面与深度**）
4. **输入**：翻书 → 影像追忆口述 → 提纲；检索课堂画面与旧题；当晚睡前再追忆（两日三记）；模糊→精确靠时间与专注
5. **输出**：听极速学习音频 → 限时答题记分；不纠结对错与左右脑，接纳分析与直觉
6. **三错一讲**：选三道错/难题；设想自己是老师怎么讲；可先列提纲；文理互借（理得清楚 × 讲得明白）
7. 扩充数据库、加强检索（专属「搜索引擎 + 百科」）
8. **自主安排一件家务 / 运动**
   - 右脑：简单重复持久劳动，或 >40 分钟有氧（练耐性）
   - 左脑：规划型事务（收纳、采购优先级等，练关联）
9. 收工犒劳自己
