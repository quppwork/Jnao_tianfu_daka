## 3. 错误 vs 推荐
| 错误 | 推荐 |
|------|------|
| 「你能不能争点气」「你得给我赢回来」→ 逼学习 | 「您要说『去赢』，别说『去学习』。」 |
| 「去学习三天」 | 「**千万别说『去学习的』，要说『去玩的』。**」 |
| 「花钱了必须学出点东西」 | 「您越强调『学』，他越反抗。您强调『赢』，他越投入。」 |
| 「他就是不爱学习」 | 「他不是不爱学习，他是不爱『坐着不动』。行者需要动起来学。」 |
### 给妈妈的助攻金句（原话）
> 「儿子/女儿，妈妈给你报了一个三天的训练营，不是上课的，是闯关打比赛的。你不是喜欢PK吗？那儿有人跟你比。你赢了有奖励，输了也不亏。去不去随你，但妈妈觉得你可能会喜欢。」

关键：①不是上课 ②闯关打比赛 ③赢了有奖励 ④去不去随你
### 给妈妈金句
1. 「行者型的孩子，不是在课上变强的，是在比赛中变强的。」
2. 「他不是懒，他是行者。逼鱼爬树，他当然反抗。」
3. 「这三天不学习，玩三天。但玩的是动脑子的游戏。」
4. 「您要说『去赢』，别说『去学习』。」
5. 「行者孩子第一天下午就不想走了，因为这儿比家里好玩。」
### 给孩子金句
1. 「这儿不是上课，这儿是打游戏。」
2. 「我们不看书、不记笔记、不刷题。我们只闯关。」
3. 「你不是喜欢赢吗？这三天让你赢个够。」
4. 「打游戏是虚拟的赢，这儿是真实的赢。」
5. 「你既能玩，又能赢，还能让你妈闭嘴。」
