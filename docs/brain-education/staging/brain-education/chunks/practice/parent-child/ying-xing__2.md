## 2. 核心冲突
```
赢者妈妈：结果 / 效率 / 赢 / 面子 →「争点气」「给我赢回来」
        ↓
行者孩子：好玩 / 刺激 / 即时反馈 → 静止=痛苦，运动/竞争=兴奋
        ↓
妈妈越强调「去学习」，孩子越不来
```

**真洞察**：行者不是不想来，是**标签错了**。

> **口径**：本方案中的「行者」属**好动偏赢型**（主行+外显精力/竞争）。理论主画像另有「封闭务实」一面——招生用本卡，日常封闭型见 [../talents.md](../../foundations/talents.md) §2.4 与 [../talents-application.md](../talents-application.md) §5.4。
