[脑科学教育 · L2 practice/parent-child · ying-xing.md · 对赢者妈妈]

### 对赢者妈妈
> 「姐，我知道您要什么——**您要的是结果，是赢……** ……行者型来了，效果往往最明显。……**巧了，我们这儿不学习，我们玩三天。**」

> 「……**您孩子不是懒，他是行者。行者的孩子，大脑就是在动中学习的。** ……逼鱼爬树……」
### 对行者孩子
> 「……**这儿不是上课，这儿是打游戏。** ……不看书、不记笔记、不刷题。我们只做一件事——**闯关。** ……积分……排行榜……团队赛……单挑……**你赢得多，奖励就多。**」

> 「……**我这儿没有『坐那儿不动』这个选项。** ……**你不是喜欢赢吗？这三天让你赢个够。**」

> 「……不叫它『学习』，我们叫它『训练』。……**这三天，比你打三天游戏还爽。因为打游戏是虚拟的赢，这儿是真实的赢。**」
### 卡壳速查
| 卡壳 | 应对 |
|------|------|
| 「不爱学习怎么办」 | 「不爱坐着不动；需要动起来学。」 |
| 「不就是补习班吗」 | 「补习班坐着听课，我们站着比赛。」 |
| 「怕光顾着玩」 | 「玩中学效果最好；越投入进步越快。」 |
| 「去了能干嘛」 | 「PK、闯关、积分、排行榜；赢了当场有奖励。」 |
| 「花钱必须学出东西」 | 「强调『学』→反抗；强调『赢』→投入。」 |
### 一句话总结
> 「赢者的妈，你别催他学习，你催他去赢。行者的娃，这儿不是上课，是打游戏闯关——赢了当场有奖励，输了也不亏。你来三天，比打三天游戏还爽。」
