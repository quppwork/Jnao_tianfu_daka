## 3. 错误 vs 推荐
| 错误 | 推荐 |
|------|------|
| 「你听我说完」「利弊我都分析清楚了」 | 「**不是论证，是提供信息，然后闭嘴。**」 |
| 「我已经劝了一个月了」 | 「**您劝了一个月，相当于在他心里的『信用额度』刷爆了。**」 |
| 「我花了钱，他必须去」 | 「**花了钱选择放手，才是真正的聪明。**」 |
| 犹豫时补一句「你倒是决定啊」 | 「这时候您不能催……」 |
### 助攻句 A（实战话术 · 第三方背书）
> 「儿子/女儿，妈妈不逼你。但我觉得那个老师说得有道理，你要不要去看看？就算不满意，也就一上午，没什么损失。妈妈尊重你的决定。」
### 助攻句 B（真实案例 · 学者人设）
> 「儿子/女儿，妈妈研究了一下，觉得这个地方可能有价值。这是资料，你自己看看，去不去你自己决定。妈妈不干涉。」

关键：①我研究了一下（学者面子）②你自己看看③你自己决定④妈妈不干涉
→ 「真正的聪明，是分析清楚之后，选择不说。」
### 给妈妈金句
1. 「您分析得越清楚，孩子越不听——因为思者不需要被论证，他需要自己做决定。」
2. 「逻辑上您赢了，关系上您输了。」
3. 「学者型妈妈最高级的做法：分析清楚之后，选择不说。」
4. 「思者判断错一次，比被安排一百次成长得更快。」
5. 「您要的不是控制结果，是给孩子一次做决定的机会。」
6. 「您退一步，他进一步。」
7. 「花了钱选择放手，才是真正的聪明。」
### 给孩子金句
1. 「我不是来替她完成说服任务的，我是来给你信息的。」
2. 「Option A：不来，继续现状。Option B：来看看，不满意就走。从风险收益比，B 期望值更高。」
3. 「你要的不是正确答案，你要的是自己能做决定。」
4. 「这个地方不是来教育你的，是来展示你的。」
5. 「我们不刷题、不背书。我们教的是怎么用你的大脑。」
6. 「这不是你妈让你来的，这是你自己决定要不要获取更多信息。」
7. 「您用两小时验证，比您妈用两小时论证更有价值。」
