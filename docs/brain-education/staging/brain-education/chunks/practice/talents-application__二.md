## 二、十大优点 × 十大缺点（相生辨证词库）
> 物极必反：某一优点越强，成对缺点往往越显。辅导时两边一起看。
### 2.1 思者
| 优点 | 成对缺点（方向） |
|------|------------------|
| 高尚奉献 | 不懂拒绝 |
| 善谋重思 | 缺乏自信 |
| 积极创造 | 持续力差 |
| 灵性启发 | 心高空想 |
| 自由冒险 | 懒惰拖沓 |
| 思考探究 | 说教嫉妒 |
| 艺术浪漫 | 自大优柔 |
| 真理哲学 | 不切实际 |
| 耿直仁慈 | 易怒急躁 |
| 正义率真 | 轻信他人 |

**总诀**：求仁 · 正木善变 · 心无设限 · **不韧需行**
### 2.2 赢者
| 优点 | 成对缺点（方向） |
|------|------------------|
| 领袖果断 | 手腕强硬 |
| 善途众赢 | 失得脆弱（输不起） |
| 想象感染 | 自我冲动 |
| 沟通表达 | 好强争辩 |
| 性急进取 | 诡诈善妒 |
| 事业力强 | 排除异己 |
| 热情好客 | 自私傲慢 |
| 自信美感 | 浮躁吹嘘 |
| 守礼至尊 | 偏执记恨 |
| 魄力激情 | 强势独断 |

**总诀**：求礼 · 火急善争 · 善借营势 · **不勤需学**
### 2.3 德者
| 优点 | 成对缺点（方向） |
|------|------------------|
| 奉献责任 | 伪装懦弱 |
| 善守重德 | 优柔寡断 |
| 细腻观察 | 多愁善感 |
| 和谐耐心 | 敷衍麻木 |
| 和气不争 | 卑躬屈膝 |
| 情感丰富 | 精力分散 |
| 慈悲博爱 | 博而不精 |
| 浪漫温情 | 依赖讨好 |
| 守信重诺 | 抱怨放纵 |
| 稳定信赖 | 被动安逸 |

**总诀**：求信 · 重土善厚 · 不动如山 · **不变需思**
