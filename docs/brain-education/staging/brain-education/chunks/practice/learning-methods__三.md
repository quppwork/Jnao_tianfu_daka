## 三、家庭组合学习力
> 原书有「家庭组合学习力参数表」图，正文**未给出完整数字矩阵**；仅保留判定口径。

| 家长分 + 孩子分 | 含义 |
|-----------------|------|
| **≥80** | 学习上基本不用太担心 |
| **60–80** | 谁分低谁拖后腿 |
| **&lt;60** | 父母行动决定孩子学习结果 |

原则：未成年受家庭影响深；提升孩子学习力必须同时管**成人自己的情绪**。
### 3.1 居家因材施教
| 类型 | 建议 |
|------|------|
| 思 / 赢（右脑） | 思者有事可忙、赢者有「赚」（家务可发「工资」）；体力作家务 → 学习时专注够；**规矩 > 讲歪理**；赏罚清晰，可约翻倍后果并严格执行 |
| 德 / 行（左脑） | 多开口说、多关爱、多做主（点菜/购物/行程）；**讲道理 + 陪伴监督** |
| 学者 | 赏识第一；点到为止留面子 |

> **交付红线**：禁止体罚与人格羞辱。左脑「绝对不能打」；右脑书中「幼年打手板」实操一律改为规则 + 自然后果 + 即时奖惩。12 岁后更要以规矩与契约为主。
