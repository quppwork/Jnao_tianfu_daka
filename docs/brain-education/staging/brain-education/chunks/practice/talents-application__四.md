## 四、培养口诀与因材施教法
| 天赋 | 三句口诀 | 方法一句话 |
|------|----------|------------|
| 思者 | 少就是多 · 意愿第一 · 效率第一 | 用不努力也能学会学好的方法 |
| 赢者 | 少就是多 · 奖励第一 · 结果第一 | 设定目标，唤醒企图心 |
| 德者 | 思才是学 · 监督第一 · 过程第一 | 每天进步一点点，持续增压 |
| 行者 | 思才是学 · 情绪第一 · 行动第一 | 薄弱环节精准刻意练习 |
| 学者 | 干扰成才 · 规划第一 · 效率第一 | 综合提效，并允许不完美 |
### 高效学习时长参考（素材口径）
| 天赋 | 单次高效窗口约 |
|------|----------------|
| 思者 | ≤15 分钟 |
| 赢者 | ≤25 分钟 |
| 德者 | ≤35 分钟 |
| 行者 | ≤45 分钟 |
| 学者 | ≤45 分钟 |

设计日计划时：**短而频**优先于一次坐很久（尤其思者 / 赢者）。
