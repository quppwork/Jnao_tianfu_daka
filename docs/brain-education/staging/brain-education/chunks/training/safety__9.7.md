### 9.7 一线老师「遇事怎么办」速查
```
出现异常
  ├─ 疼痛 / 睡眠乱 → 9.1.1（快/中/慢/外力；用药问医生；查是否晚练）
  ├─ 高敏感 → 立刻停感知类，改照相机记忆 / 极速运算
  ├─ 感知幻觉 → 进潜意识训练 / 安全引导；恐惧则家长先学
  ├─ 焦躁暴力 → 先运动消耗，再评估强度
  ├─ 问题加重 / 幻视听 → 家长学习 + 设备保护；脚本内应对
  ├─ 逃避 / 自我否定 / 极端 → 立刻专业人士
  ├─ 晚练兴奋 → 禁止 22:00 后训练
  └─ 课上会、课后不会 → 查稳定性 + 亲子 + 学科愉悦度
```
