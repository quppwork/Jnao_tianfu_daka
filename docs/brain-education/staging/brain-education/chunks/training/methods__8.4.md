### 8.4 视力修复（眼脑配合 · 非替代就医）
| 红线 | 说明 |
|------|------|
| 病理性 / 器质性眼病、发育问题 | **及时就医**；与脑力训练无直接因果，可互补不冲突 |
| 本章提升对象 | 含视神经在内的**大脑图像处理**整体视力功能 |
| 医院趋势（书中） | 眼科与神经内科协同；眼脑配合训练逐步普及 |
#### 8.4.1 第一部分：眼脑配合（变焦白片）
- 模糊图出现 → 大脑自动「清晰化」；强度 ∝ 脑力 + **想看清的意愿**
- 意识给潜意识「变清楚」指令 → 潜意识执行；依赖左右脑配合
- 清晰↔模糊反复切换 → 频繁执行指令直至内化 → 刺激视觉功能区
- 变焦白片自适配速度，一般由慢到快
- **物理侧**：刺激睫状肌收放（晶状体调焦「跑步机」）
  - 久看近 → 睫状肌痉挛难放松 ≈ 近视叙事
  - 年长肌无力、难调近 ≈ 老花叙事

注（书中澄清）：眼轴 = 角膜到视网膜距离；晶状体焦距 = 光学焦长 —— **都不是**某个可单独「摸到」的构件名。
#### 8.4.2 第二部分：加强第三视力（变焦红蓝片）
- 第三视力：大脑渲染、关联、补图（见 [theory.md](../foundations/theory.md) 三级视力）
- 红蓝镜片提供双眼不同图像 → 大脑合成立体 → 高阶图像处理 + 助内视力 → 反哺扫描速记等
#### 8.4.3 适用性（书中口径 · 需核实效果数据）
| 情况 | 书中 |
|------|------|
| 近视 / 远视（焦点在视网膜前/后） | 白片 + 红蓝片均有效叙事 |
| 散光（视轴弯曲偏离） | 睫状肌训练作用不明显 → **红蓝片**有效叙事 |
| 戴镜 / 曾激光手术、基本正常眼 | 可有不同程度提升叙事 |
| 角膜 | 不因本训练改变 |

设备让训练减枯燥、提成效——与 [technology.md](../frontline/technology.md) 交叉。
