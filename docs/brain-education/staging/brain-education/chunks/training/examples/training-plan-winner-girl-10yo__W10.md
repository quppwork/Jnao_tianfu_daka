### W10 · 极速学习 + 拨动导读（三段）
**本周目标**：1 篇课文/1 章历史：读 → 导图 → 调取运用
#### 主能力：拨动导读（20 min）
```
极速读完（5 min）→ 自己画思维导图（8 min）→ 合上书调取（7 min）
```

**关键**（来自理论）：

- 背别人的思维导图无意义
- 必须**自己画、自己讲、知道具体内容**
#### 验收
| 项目 | 标准 |
|------|------|
| 导图 | 至少 3 层，≥8 个节点 |
| 合书调取 | 能按导图讲出 ≥80% 内容 |
| 运用 | 能答 2 个「为什么/怎么用」 |

### W11 · 拨动导读 + 缩段成句启蒙（三段巩固）
**本周目标**：把 1 堂课内容压成 4 句押韵小诗
#### 主能力：缩段成句启蒙（20 min）
| 步骤 | 做法 |
|------|------|
| 1 | 选今天某一科，影像追忆课堂 |
| 2 | 列出 4–6 个关键词 |
| 3 | 编成 4 句押韵小诗（不要求完美，求押韵+覆盖知识点） |
| 4 | 背诗 → 从诗「翻译」回知识点 |

**案例参照**（训练体系）：优秀学员每天每堂课写一首押韵诗，坚持一年考全校第一。10 岁先做**启蒙版**，每天 1 首即可。
#### 示例（数学·小数乘法）
```
小数乘整数，先当整数算，
数完点位置，数位要细看，
积的小数点，对齐最关键，
验算不能少，女王不会乱。
```
