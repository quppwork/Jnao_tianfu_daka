[脑科学教育 · L5 frontline · products.md · 导师权益]（宣传数据 · 须核实，非承诺）

### 导师权益
- 子女成长计划 + 3 年十期火箭提分营保障
- 优秀导师孩子四次集训后可成小助教，参加集训来挣钱而非花钱
- 成人课程、子女专属音频、专家指导、线上训练营、天赋课程
- 招商资格、零售资格、晋升督导/专家/主播/核心高管
### 导师要求（优先级）
1. 人品道德 > 敬业态度 > 专业技能
2. 分享助人 > 专业技能
3. 诚实真实 > 业务能力
4. 排斥：不择手段、只自学不教、光搞钱不管人
### 组织架构
- **四合一模式**：专家带多个导师
- **教育学院**：专家团带教
- **管理团**：创始人 + 核心班子，教天赋运用
- **播商学院**：教学负责人主抓
### 晋升路径
```
入门导师 → 督导 → 专家/股东（公司上市分红，不用投钱）
```
### 收益参考（演讲数据）
- 专家导师团平均月入 1–3 万
- 实习底薪 2000；开干后底薪 5000–8000，优秀专家底薪 1 万
- 十人火箭提分营新人 → 课时费 5000 + 业务提成最高 5%
