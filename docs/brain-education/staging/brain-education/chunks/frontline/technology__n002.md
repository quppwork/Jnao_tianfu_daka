### 「变聪明」机制（书中公式）
```
目的：信息传递效率高
本质：树突 + 轴突链接更多、更粗（突触交织）
状态：触发并维持 α 脑波
方法：感官输入 → 潜意识植入
机制：刺激且反复刺激（重复）
载体：规划好的学习需求
原则：用进废退
```
### 四种脑波与训练窗口
| 脑波 | 频率 | 训练相关 |
|------|------|----------|
| δ | 0.4–4 Hz | 深睡 |
| θ | 5–7 Hz | 浅睡 / 入定 / 催眠；利长期记忆；高暗示性 |
| α | **8–13 Hz** | **意识—潜意识桥梁**；学习与灵感最佳；可迸发、可积累 |
| β | 15–40 Hz | 清醒努力专注 |

α 细分：慢 8–9 / 中 9–12（灵感专注）/ 高 12–13（高度警觉）。
深睡、激动、恐惧、愤怒时通常**没有** α。
