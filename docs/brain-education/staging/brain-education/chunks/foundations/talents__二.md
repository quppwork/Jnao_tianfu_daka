## 二、五者天赋的分类（第三章精读）
> 对应书：**三、五者天赋的分类**（§1～§5）。
> 每节结构：标语 / 脑型·五行 → 动物意象 → 正文画像 → 代表人物（书中举例）→ 特性卡 → 交付要点。
### 2.1 思者—极右脑型（鹰的视野）
| 项 | 书中口径 |
|----|----------|
| **标语** | 思者智在九天，创意无限，天马行空，活在梦里 |
| **脑型** | 右脑**极度**发达，左脑相对很弱 |
| **五行** | 木 — 「木」具有**生发、条达**的特性 |
| **意象** | 鹰的视野 |
| **主能力** | 创造力；点子多，执行差 |
| **书中举例** | 爱因斯坦 · 乔布斯 · 毕加索 |

**画像（顾问可照讲）**：

- 时常遨游在自己的世界里；左脑经常休息 → 易丢三落四、难以集中；**专注力很低，走神往往不是故意的**
- **只做喜欢 / 感兴趣的事**；意愿度高时，速度与效率惊人
- **学习内驱核心**：用更短时间把学习学好，让其有**优越感**
- 善于挑战权威，但不颠倒是非；非常真诚
- 看重**生命价值**；常问「这一生为什么而活」；会担忧遥远未来；分析当下多取**宏观视角**
- 书中金句：伟大科学家通常右脑高度发达；思者不做点伟大的事很可惜

**特性卡**：

| 正面 / 习性 | 怕什么 | 口诀 |
|-------------|--------|------|
| 白日梦，很懒惰，忘性大，不记仇；善顶嘴，找借口，很善良，小聪明 | 无聊，讲大道理，过度监督，打击自信 | 懒惰高效 · 少就是多 · **意愿第一 · 效率第一** |
