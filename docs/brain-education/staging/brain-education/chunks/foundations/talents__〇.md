## 〇、从第二章接到五者（桥接必读）
> 对应书：第二章收束句 → 第三章开篇。

《超脑进化之书》第二章用割裂脑实验说明：两半球功能不对称（单侧化），正常时经胼胝体协同；**左右半球协作方式不同 → 性格与天赋差异**。
书中并把右脑与**潜意识**叙事挂钩：人有两套意识，右脑（潜意识）甚至比左脑更独立。

第三章开篇：

> 由于大脑功能的不同，导致每个人的天赋有所差异。
> 根据左右脑的发达程度，将天赋种类区分为极右脑型、右脑型、左右平衡型、左脑型、极左脑型。
> 分别称之为：思者、赢者、学者、德者、行者。

```
极右脑 ─── 右脑 ─── 左右平衡 ─── 左脑 ─── 极左脑
  思者      赢者      学者        德者      行者
```

| 脑型光谱（书第三章一句话列举序） | 者型 | 主天赋 | 五行 |
|----------------------------------|------|--------|------|
| 极右脑型 | 思者 | 创造力 | 木 |
| 右脑型 | 赢者 | 想象力 | 火 |
| 左右平衡型 | 学者 | 专注力 | 水 |
| 左脑型 | 德者 | 观察力 | 土 |
| 极左脑型 | 行者 | 记忆力 | 金 |

**两个顺序不要混**：

| 用途 | 顺序 |
|------|------|
| 讲「从右到左的脑型光谱」（书中一句话列举） | 思 → 赢 → **学** → 德 → 行 |
| **正文分节序 / 交付身份证 / 短剧 / 口令铁律** | **思 → 赢 → 德 → 行 → 学** |
