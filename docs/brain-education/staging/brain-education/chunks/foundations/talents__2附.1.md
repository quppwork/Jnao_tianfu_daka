### 2附.1 创造力（思者 · 正木）
| 项 | 书中口径 |
|----|----------|
| **气质** | 随机应变、举一反三；不易受固有心理定势干扰；能产超长构想与新概念 |
| **双重身份** | 既是思者先天特质，又是大脑复杂使用的**流程环节** |
| **思维成分** | 跳跃性思维 + 发散性思维（无定向、无拘束，由已知探未知） |
| **与观察** | 观察 = 弹药 / 钢筋水泥；创造 = 枪炮 / 结构设计 —— 无观察的创造易空想；无创造的观察只是围观 |

**三要素流程**：

1. **观察与理解**：发现→吸收→巩固；鉴别提炼 = 创造力前身
2. **专注与逻辑**：专注打开潜意识 →「灵光一现」；再用形态分析、矩阵、思维脑图做系统整理
3. **创造与想象**：右脑泉涌；建立个人**聚合思维**模型（发散=食材，聚合=炒锅）

**高创造力人格（书中）**：兴趣广、语言流畅、幽默、反应敏捷、思辨严密、独立、少从众、自尊强、喜抽象、社交尚可、抱负高、直率坦白——实为**思+赢+行**特质综合的「金三角」。

**训练捷径**：木（思）火（赢）相生先修；木金（行）相克后修。

**形态分析法（茨维基 / 书中火箭周产 576 方案典故）**：系统拆分功能部件 → 各部件方法穷举 → 再组合。书中「电脑主机箱 6×6 格子」示例：颜色×材质×功能×形状×附加×图案 → 可至数万级组合；再加年龄段需求可至约 **27 万**组合——教学用来演示「观察甄别 + 逻辑组合 + 专注选优 = 创意」。

**教育隐喻**：创造力不是教人「用腿追上汽车」，是给车钥匙 / 飞机钥匙 + 驾驶课；由创造**拣选**知识，而非囤积闲置库存。

**源力 32 字**（与 §三 一致）：

> 思者善变，源力创造；积极创造，灵性启发，正义率真，创新重组，跳跃思维，宏观思考。

**思者发挥要点**：创造力自内而发、伴随终生；正义初心易激发创造；A→B 跳跃、路径模糊；知识匮乏时「宏观」变「夸夸」→ **充分武装知识**才能真正发挥潜能。
