## 一、第一章总览：大脑、感官与「科学走在教育前面」
> 对应书：**一、潜意识和意识** 开篇。
### 1.1 大脑 ≠ 思维（mind）
| 概念 | 书中口径（便于跟家长讲） |
|------|--------------------------|
| **大脑** | 身体的一部分，生理器官的实际存在 |
| **思维（mind）** | 大脑的功能；神经元链接时末梢电位差产生电信号 |

心理学谈潜意识、科技谈脑科学，都是**持续发展中**的学科——所以教育方法也要跟着科学更新：**科学一直走在教育前面**。
### 1.2 五感（显性）与第六感（隐性）
**显性五感**：视、听、嗅、味、触 —— 各有对应器官。人类眼球高度进化 → **视觉是最强感官通道**。

**隐性通道（书中举例）**：

- 沟通时：表情、肢体、语气
- 学习时：文字、图形、心灵默契感
- 其它：对不同地点人事的远程感知等

以上五感之外统称 **超感官直觉 / 第六感**。

**学科归类（顾问口诀）**：

```
五感     → 生理学
第六感   → 潜意识范畴
识别判断 → 大脑综合处理（大脑功能）
```

大脑能力与敏感度，与人的**天赋、状态**密切相关（为后文五者差异埋伏笔）。
