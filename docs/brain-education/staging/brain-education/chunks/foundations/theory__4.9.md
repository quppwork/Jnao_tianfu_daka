### 4.9 通往五者的关键句（第二章收束）
书中把实验结论接到天赋体系：

1. **人有两套意识**
2. **右脑（潜意识）甚至比左脑更独立**（与第一章潜意识叙事衔接）
3. **左右半球的协作方式** → 造成人的**性格与天赋差异**

下一章据此按左右脑发达程度分为：极右 / 右 / 平衡 / 左 / 极左 → 思者、赢者、学者、德者、行者（顺序与脑型对应见 [talents.md](talents.md)）。

| 脑型（第三章） | 者型 |
|----------------|------|
| 极右脑型 | 思者 |
| 右脑型 | 赢者 |
| 左右平衡型 | 学者 |
| 左脑型 | 德者 |
| 极左脑型 | 行者 |

> 注意：书中第三章开篇列举顺序是「思、赢、学、德、行」（按脑型光谱）；交付身份证仍用铁律顺序 **思→赢→德→行→学**。

### 4.10 第二章交付红线与口诀
| 红线 / 口诀 | 说明 |
|-------------|------|
| **不神化「开发右脑」** | 实验证明的是分工与单侧化，不是「右脑万能」；全脑教育强调的是**平衡与协作** |
| **不恐吓割裂脑** | 后遗症只说明切断连接的代价；训练从不切断，只练互通 |
| **口诀** | 胼胝体是高速；切断才分裂；正常要协同；特长靠单侧化；协作方式定天赋 |
| **亲子沟通** | 右脑型 / 左脑型沟通总则 → [talents-application.md](../practice/talents-application.md) §5.6 |
