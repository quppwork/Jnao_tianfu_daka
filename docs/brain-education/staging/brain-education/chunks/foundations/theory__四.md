### 4.0 本章一句话
```
胼胝体切断 → 两半球可独立研究
     ↓
功能不对称（单侧化优势）
     ↓
协作方式不同 → 性格与天赋差异
     ↓
五者分类（第三章）
```

### 4.2 生理前提：胼胝体与对侧支配
要理解割裂脑，先记住三条生理底线：

| 概念 | 说明 |
|------|------|
| **胼胝体**（pián zhī tǐ） | 约 **2 亿根**神经纤维构成的「两半球高速公路」 |
| **切断后** | 主要连接被断 → 两半球功能**彼此独立**；可单独研究各自功能（Sperry, 1974） |
| **对侧支配** | 每个半球主要对**身体对侧**刺激做反应，并调节对侧运动 |

```
左半球 ←→（胼胝体）←→ 右半球
切断胼胝体 ≈ 拆掉高速，两边各自为政
```
