## 三、源力三十二字诀（本道说明书）
> 与第四章各节「源力 32 字」同出一系；下表便于一张表背诵。与第三章画像互补。

| 者型 | 三十二字 |
|------|----------|
| 思者 | 善变，源力创造；积极创造，灵性启发，正义率真，创新重组，跳跃思维，宏观思考 |
| 赢者 | 善争，源力想象；想象感染，沟通表达，魄力激情，构想成像，目标思维，阶梯思考 |
| 德者 | 善后，源力观察；细腻观察，和谐耐心，稳定信赖，关微尽心，宽度思维，横向思考 |
| 行者 | 善韧，源力记忆；聪慧强记，直觉敏锐，外冷内热，过目不忘，垂直思维，深度思考 |
| 学者 | 善勤，源力专注；专注认真，严谨周到，谨慎秩序，专心分析，立体思维，多元思考 |
### 3.1 思维方式（A→B 路径差异）
| 者型 | 从起点 A 到终点 B 时 |
|------|----------------------|
| 思者 | 直接「看见」终点成像，中间路径模糊 → 懒走过程，易空想 |
| 赢者 | 终点方向清，近阶目标与路径清 → 阶梯推进 |
| 德者 | 终点成像弱，先横向扫有利/不利，平衡后才动 |
| 行者 | 终点不清，但最近可执行步骤极清 → 步步为营 |
| 学者 | 综合赢/德/行：阶段目标 + 利弊 + 可执行性 → 立体决策 |
