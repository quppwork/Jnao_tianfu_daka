## 一、系统总览

### 1.1 三层体系

```
┌─────────────────────────────────────────────────┐
│  第一层：阶位（Tier 1-9）                          │
│  决定：练哪些技能、达标标准是什么                      │
├─────────────────────────────────────────────────┤
│  第二层：学段（1-3年级 / 4-6年级 / 初中 / 高中）        │
│  决定：同一阶位内不同年级的具体阈值                     │
├─────────────────────────────────────────────────┤
│  第三层：每日训练安排（Decision Tree + 权重引擎）        │
│  决定：今天练什么技能、每个技能练几轮                    │
└─────────────────────────────────────────────────┘
```

### 1.2 三条推进线（互不等待）

```
线1：每日训练安排          线2：技能 Tier 独立晋级      线3：整体 Tier
今天练什么                 影像追忆 Tier 1→2          所有活跃技能中
由 Decision Tree           需连续3次达标               取最低 Tier
+ 权重引擎决定             各走各的互不等待              = 最低原则
```

### 1.3 核心原则

```
必修（权重引擎管）              选修（Toggle 管）
─────────────                  ──────────
expand_formula 按权重排         toggle_elective_item
blocks_next=true 阻塞下级       blocks_next=false
参与晋级判定                    auto_complete 自动标完成
计入完成计数                    不计入 progress

两者完全隔离。
```

## 四、每日排课架构：Decision Tree + Strategy Pipeline

### 4.1 总览

```
PlanRequest(minutes, tier, grade_band, skill_tiers, history)
                              │
┌─────────────────────────────┼─────────────────────────────┐
│                    Layer 1: Decision Tree                  │
│                                                             │
│   条件节点 ──True──→ 条件节点 ──True──→ 叶子: 策略名+参数   │
│      │       False      │       False                       │
│      ▼                  ▼                                   │
│   下一个节点          下一个节点                               │
│                                                             │
│   沿树走到叶子 → 输出 (strategy_name, params)                 │
└─────────────────────────────┬─────────────────────────────┘
                              │ (strategy_name, params)
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   Layer 2: Strategy Registry                 │
│                                                             │
│   每个策略 = 命名 Phase 序列。Phase 间通过 PlanContext 传递。 │
│   Phase 跨策略复用。frozen PlanContext + evolve() 不可变。    │
└─────────────────────────────┬───────────────────────────────┘
                              │
                              ▼
                      PlanResult
```

### 4.2 Decision Tree（当前）

```
                        check_consecutive_14
                               │
                 ┌─────────────┴─────────────┐
                 │ True                       │ False
                 ▼                            ▼
          force_upgrade              check_consecutive_7
         (强制≥40min,                    │
          捆绑排课)            ┌──────────┴──────────┐
                              │ True                 │ False
                              ▼                      ▼
                     compensate_diversity    check_tier_bundle
                     (轮换 + 引入多元感知)          │
                                        ┌─────────┴─────────┐
                                        │ True               │ False
                                        ▼                    ▼
                                 weight_with_bundle    normal_weight
                                 (捆绑 + 权重贪心)      (纯权重贪心)
```

### 4.3 四个策略

| 策略 | 触发条件 | Phase 序列 | 说明 |
|------|---------|-----------|------|
| `weight_based` | 默认 | slots → greedy_fill → annotate → tag | 标准权重贪心 |
| `weight_with_bundle` | Tier 3 | slots → require_bundle → greedy_fill → annotate → tag | 捆绑 + 权重 |
| `diversity_round_robin` | 连续 7 天 ≤20min | slots → round_robin_fill → annotate → tag | 轮换排课 |
| `forced_upgrade` | 连续 14 天 ≤20min | override_min → slots → require_bundle → greedy_fill → annotate → tag | 强制 ≥40min |

### 4.4 PlanContext（不可变状态）


## 六、权重表 + 衰减规则

### 6.1 各阶权重（归一化到 1.0）

```
        A超脑  B影像  C扫描  D极速  E极学  F文科  G理科  H绘画  I音乐  │  Σ
Tier 1: 0.40   0.35   0.12   0.08   0.05    —      —      —      —    │ 1.0
Tier 2: 0.25   0.35   0.25   0.10   0.05    —      —      —      —    │ 1.0
Tier 3: 0.05   0.30   0.28   0.22   0.15    —      —      —      —    │ 1.0
Tier 4: 0.03   0.28   0.26   0.23   0.20    —      —      —      —    │ 1.0
Tier 5: 0.02   0.18   0.16   0.14   0.10   0.20   0.20    —      —    │ 1.0
Tier 6+:  —    0.22   0.18   0.16    —      —      —    0.22   0.22  │ 1.0
```

### 6.2 重点 vs 次要

```
Tier 1:  重点=A,B           (×0.7)    次要=C,D,E     (×0.5)
Tier 2:  重点=A,B,C         (×0.7)    次要=D,E       (×0.5)
Tier 3:  重点=B,C,D,E       (×0.7)    次要=A         (×0.5)
Tier 4:  重点=B,C,D,E       (×0.7)    次要=A         (×0.5)
Tier 5:  重点=全部6项       (×0.7)    次要=A         (×0.5)
Tier 6+: 重点=全部5项       (×0.7)    —
```

### 6.3 贪心算法

```
① 确定性选取：每轮取 max(权重) → 不抽卡
② 重点技能衰减 ×0.7，次要技能衰减 ×0.5
③ 权重 < 0.01 → 从候选池排除
④ 算法自动产生"短时重点主导、长时多样化"的效果
```

**状态转移**：
```
W(0) = tier_weights[tier]          (Σ = 1.0)
每轮: i = argmax(W(t))
     w_i(t+1) = w_i(t) × d_i
     w_j(t+1) = w_j(t)  (j ≠ i)
```

**效果**：选中技能衰减 → 总和 Σw 下降 → 未选中技能相对权重自动上升。

## 七、Tier 3 捆绑规则

### 7.1 四种捆绑类型

极速运算(D) 在三阶首次引入，必须与另一技能配对。

| 编号 | 组合 | 时长 | 槽数 | 说明 |
|:---:|------|:---:|:---:|------|
| B1 | 多元感知 + 极速运算 | 40min | 2 | 感知力辅助 |
| B2 | 扫描速记 + 极速运算 | 40min | 2 | 初高中生标记「不推荐」 |
| B3 | 影像追忆 + 极速运算 | 40min | 2 | 影像巩固 |
| B4 | 极速运算 + 极速学习 | 60min | 3 | 运算→学习进阶链 |

### 7.2 捆绑选择机制：个体技能 Tier 优先

```
① 取捆绑中每个必修技能的用户个体 Tier，取最低值
② 最低 Tier 越小的捆绑，优先级越高（该技能更需要练习）
③ 最低 Tier 相同时，按技能编码字母序 A > B > C > D > E
④ 选修技能不参与比较 → B1 始终优先级最低
```

**示例**：用户个体 Tier：影像追忆(B)=3, 扫描速记(C)=2, 极速运算(D)=1, 极速学习(E)=2

```
B2: C(tier=2)+D(tier=1) → min=1, code=C  → 第1优先 ← 扫描速记最需要练习
B4: D(tier=1)+E(tier=2) → min=1, code=D  → 第2优先
B3: B(tier=3)+D(tier=1) → min=1, code=B  → 第3优先
B1: 多元感知(无)+D(tier=1) → 无必修搭档   → 第4优先
```

### 7.3 捆绑预衰减

捆绑技能在权重补位前预先衰减，避免它们继续抢占补位槽位。

```
Step A (捆绑):  选捆绑 → 捆绑中所有必修技能 ×decay
Step B (补位):  对预衰减后的权重执行贪心，直至剩余槽位耗尽
```

### 7.4 已确认规则

- **✅ 捆绑仅 Tier 3**：Tier 4+ D 回归普通权重排课
- **✅ 多元感知保持选修**：B1 中不打卡、不阻塞、不计 progress
- **✅ 初高中 B2 标记**：`grade_band ∈ {junior, senior}` → "不推荐"

## 十、达标标准与晋级

### 10.1 技能 Tier 独立晋级

```
技能 X 当前 Tier=N，打卡卡片达标：
  → 达标 → consecutive_pass += 1
  → 达标 + consecutive_pass ≥ 3 → 该技能 Tier 升到 N+1
  → 不达标 → consecutive_pass = 0（严格连续，中断重置）
```

### 10.2 整体 Tier

```
整体 Tier = min(所有活跃技能的个体 Tier)
每次打卡后重算 → 影响下次排课所用的权重表
```

### 10.3 OSS Stage/Part 推进（独立体系）

OSS Stage 和 Tier 是两套独立体系：

```
Tier 晋级                       OSS 推进
连续3次达标 → Tier+1            达标 → 同stage下一个part
达标标准随之升级                 无下一part → 下一stage第1part
                               耗尽 → 该技能不再推送音频
```

各技能起始 Stage 因天赋而异（如极速学习：行者/德者从 stage 3 开始，学者/思者/赢者从 stage 2 开始）。

### 10.4 达标标准

详见 `training_tier_thresholds.yaml`，按 技能 × Tier × 学段 三维索引：

| 技能 | Tier 1 示例（小学1-3年级） |
|------|--------------------------|
| 超脑阅读 | 3分钟800字（wpm） |
| 影像追忆 | 1500字 + 75%准确度（recall） |
| 扫描速记 | null（练但不考） |
| 极速运算 | null（Tier 3 才开始考核） |

## 十二、Core Rules（确定性）

```
① 确定性选取：每轮取 max(权重) → 不抽卡
② 重点技能衰减 ×0.7，次要技能衰减 ×0.5
③ 权重 < 0.01 → 从候选池排除
④ 课时槽位 + 高效作业/极速学习 额外追加（§5）
⑤ 选修不受权重引擎影响（§1.3）
⑥ ≥480min 追加精力恢复
```

## 十六、OSS Stage/Part 推进

### 16.1 推进规则

```
技能 X 当前 (stage=N, part=M)

每天打卡该技能 → 产生打卡卡片
  → 判断是否达标
    → 达标 → consecutive_pass += 1
    → 达标 + consecutive_pass ≥ 3
      → 推进到下一个 (stage, part)：同 stage 找 part+1；无则 stage+1, part=1
      → consecutive_pass = 0
    → 不达标 → consecutive_pass = 0（严格连续，中断重置）
```

### 16.2 关键原则

- **OSS Stage 和 Tier 是两套独立体系**：OSS 推进按音频实际存量，Tier 晋级按达标标准
- **天赋决定起始 Stage**：极速学习 行者/德者从 stage 3 开始，学者/思者/赢者从 stage 2 开始
- **耗尽终止**：OSS 池无下一 (stage, part) 时，该技能不再推送音频
- **超脑阅读无 Stage**：单音频复用，Tier 升级只改达标标准

## 十七、天赋类型差异

| 维度 | 是否区分 | 说明 |
|------|:---:|------|
| 内容池 | ✅ | 每个天赋有独立的 OSS 音频目录（学者/思者/行者/德者/赢者） |
| 起始 stage | ✅ | 极速学习：行者/德者 stage 3，其他 stage 2 |
| 训练框架 | ❌ | 时长公式、打卡顺序、晋级规则对所有天赋统一 |
| 达标标准 | ❌ | 按学段区分，不按天赋区分 |
