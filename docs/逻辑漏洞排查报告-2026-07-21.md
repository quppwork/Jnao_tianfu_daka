## 待修复风险清单（按优先级）

### 高风险

#### 1. Part 轮换：一次打卡给所有技能计数

| 项 | 内容 |
|----|------|
| 位置 | `training_service._try_rotate_part_after_checkin` |
| 现象 | （修复前）任意技能打卡后，五个必修技能的 `part_listen_count` 各 +1 |
| 修复 | 仅对本次 `cards[].name` / 当前项 `instructions.skill` 中的必修技能计数；计数变化一律落库；首次计数写入 `part_first_listen_at` |
| 前提 | 一天一次训练，按项/卡片计即可，无需按「同日多次排课」设计 |
| 状态 | ✅ 已修（2026-07-21） |

#### 2. 新学员几乎无法自动转为老学员

| 项 | 内容 |
|----|------|
| 位置 | `training_service._auto_promote_to_returning` |
| 现象 | （修复前）存在 `onboarding.completed_at` 时直接 return，累计 ≥30 也不改 `student_type` |
| 修复 | 去掉 `completed_at` 早退；`student_type==new` 且 `TrainingRecord` 行数 ≥30 → `returning`，并写 `promoted_to_returning_at` |
| 状态 | ✅ 已修（2026-07-21） |

#### 3. 短时分支只看历史，不看今天所选时长

| 项 | 内容 |
|----|------|
| 状态 | ✅ 已消除根因（2026-07-21）：移除 7/14 短时旁路，不再有该误触发路径 |
| 替代 | 主干 `weight_based` + greedy **近史软惩罚**（`decay_rules.history_penalty`） |

#### 4. 空壳方案被计为「≤20 分钟短时天」

| 项 | 内容 |
|----|------|
| 状态 | ✅ 已修（随旁路删除 + history 净化）：`populate_plan_items` 仅纳入 `planned_minutes>0` 且有 items 的历史，排除当日壳 |
| 用途 | 现仅服务主干软惩罚，不再驱动 Decision Tree 短时分支 |

#### 5. 同日排课时 history 含「今天=0 分钟」

#### 8. 轮换「避开昨天技能」基本失效

| 项 | 内容 |
|----|------|
| 原问题 | 旧 `round_robin_fill` 用 `SKILL_CODE.get(技能名)`，但 history 里存的是 `item.title`（课名如「超脑阅读·基础」），对不上 → `last_codes` 常为空，去重无效 |
| 状态 | ⚪ 已失效（2026-07-21）：短时旁路与 `round_robin_fill` 已删除；主干用 greedy + 近史软惩罚，不再走该路径 |

#### 9. `overall_tier` 为平均再向下取整

| 项 | 内容 |

| 分支 | 实现曾用 `floor(avg)`，与主干语义分裂 |
| 修复 | 去掉 avg，改回 `min`（落后技能拖住整体档） |
| 状态 | ✅ 已修（2026-07-21） |

#### 10. 时长选择器可超过 API 上限

| 状态 | ⚪ 按设计保留（2026-07-21） |
