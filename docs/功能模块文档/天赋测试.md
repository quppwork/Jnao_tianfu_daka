## 二、页面状态机（测评页内 5 个阶段）

测评页由 `talent/index.vue` 的 `phase` 驱动；**报告不在本页**，提交后 `navigateTo` 独立报告页。

| 阶段 | phase 值 | 用户看到什么 | 用户操作 |
|------|---------|------------|---------|
| 1 | `door` | 欢迎语 + 「孩子测试」/「成人测试」 | 选择类型 |
| 2 | `ageGate` | 年龄确认：「已满18」/「未满18」 | 仅孩子测试触发 |
| 3 | `confirm` | 测试说明 + 「准备好了」/「稍后再说」 | 确认或返回 |
| 4 | `testing` | 题目 + 倒计时 + 进度条 | 「完全符合」/「有差异」 |
| 5 | `completed` | 撒花 + 「生成报告」 | 提交后离开本页 |

| 报告 | 路由 |
|------|------|
| 成人 | `/pages/report/index?assessment_id=…` |
| 儿童 | `/pages/report-kid/index?assessment_id=…` |

## 三、各阶段详细设计

### 阶段 1：大门页 (door)

**UI 元素：**
- 顶部：欢迎语（新用户 / 老用户文案不同）
- 中间：两个按钮 —「孩子测试」「成人测试」
- 可展示历史测评列表（查看 / 删除）

**关键状态：** `testType: "成人" | "孩子" | null`

---

### 阶段 2：年龄门控 (ageGate)

> 仅「孩子测试」进入；「成人测试」直接到确认页。

**UI 元素：**
- 「请确认孩子是否满18岁」
- 「已满18岁」→ 改走成人测试确认页
- 「未满18岁」→ 家长辅助提示约 2.2 秒后进入孩子确认页

---

### 阶段 3：确认页 (confirm)

**UI 元素：**
- 「好的，{成人/孩子}测试。」
- 说明：共 35 题，选项「完全符合」/「有差异」，约 10–15 分钟
- 「准备好了，开始吧」→ 进入答题
- 「稍后再说」→ 返回大门

---

### 阶段 4：答题页 (testing)

**UI 布局（从上到下）：**

```
┌──────────────────────────────────────┐
│ [成人测试]              5/35         │  顶部栏 + 进度
├──────────────────────────────────────┤
│         [上一题卡片（点击撤回）]       │  撤销区
│  ┌──────────────────────────────┐   │
│  │  第 5 题 · ⏱ 倒计时            │   │
│  │  题干…                        │   │
│  │  [完全符合]    [有差异]         │   │
│  └──────────────────────────────┘   │
│  🤖 凭第一感觉选择就好～              │
└──────────────────────────────────────┘
```

**核心逻辑：**

| 功能 | 说明 |
|------|------|
| 题目顺序 | 35 题 Fisher-Yates 随机打乱 |
| 倒计时 | 每题约 **60** 秒（`QUESTION_SEC`），末段变红 |
| 超时 | 该题排到剩余题目后半 |
| 撤销 | 点上一题卡片回退，短时内可重选 |
| 跳过 | **当前无「跳过→报告」** |
| 答题编码 | `完全符合`→`1`，`有差异`→`0`，按题号 1–35 拼成 35 位串 |

题目文案：`vue_fronted/src/data/questions.js`（后端另有 `backend/config/questions.yaml`，宜长期统一来源）。

---

### 阶段 5：完成页 (completed)

| 时间 | 内容 |
|------|------|
| 进入 | 撒花等完成动效 |
| 随后 | 「35 题已完成」+「生成报告」按钮 |

**点击生成报告 →** `POST /api/talent/report`（含 `answer` / `child_user_id` / 类型等）→ `navigateTo` 对应报告页；若有冲突/锁定，query 带上 `talent_conflict` / `talent_locked` 等。

失败时页内展示错误，可重试。

---

### 报告页（独立页面）

成人 / 儿童报告页长滚动展示（天赋名、特质、雷达、情绪仪表、建议等）。儿童报告另有「深度校准（备用卷）」入口；「重新测试」回到测评流程。

详情与确认天赋规则见 API 文档「天赋测试 / 天赋报告」。

---

## 四、数据流

```
前端 → 选类型 → 答 35 题
                 │
                 ▼ encodeAnswers()（talent/index.vue 内）
         35 位 0/1 字符串
                 │
                 ▼ POST /api/talent/report
         后端 jnao_submit → jnao_get_report
         save_assessment → 冲突/锁定检测
                 │
                 ▼ navigateTo 报告页（assessment_id + 可选冲突参数）
```
