# 天赋学院 · 剧集包模块（Episode Pack）

> 最后更新：2026-09-21  
> 目标：一集 = 一套资料；加集时只填包，不改讨论/播放/解锁主流程。  
> 产品入口：[天赋学院.md](./天赋学院.md) · 角色表：[天赋学院角色智能体.md](../天赋学院角色智能体.md)

---

## 1. 一句话

**内容按「剧集包」版本化；运行态按「用户 × 集」落库。**  
壳页、播放、解锁、开房、多智能体发言是固定流水线；换集只换包里的 meta / 感知 / 口吻 / 剧情 / 弹幕 / OSS。

---

## 2. 包里有什么（一集一套）

| 块 | 用途 | 谁消费 |
|----|------|--------|
| `meta` | id、标题、topic、task、chips、海报、时长、oss_key、是否可切集 | `catalog` → `sector` |
| `sense` | 每人在本集画里的第一感受（时间盒） | `perception.time_box` |
| `lines` | 开场/LLM 兜底口吻（按角色 2 句） | `harness._fallback`、假对话 |
| `danmaku` | 观众弹幕池 | 前端 `drama.html` |
| `plot` | 剧情摘要 / 能聊 / 还不能知道 | KB 切片、百炼、可选注入 |
| `agents`（可选） | 本集对某角色的脚本覆写 | `academy_bot_script` 或包内字段 |
| `fit_markers` | 串集检测用关键词（站桩 vs 眼罩 vs 黄巢） | `messages_fit_episode` |

共享、不随集变的部分：六个画中人稳定画像 → `characters.py` + `docs/kb/short-drama/characters/*`。

包目录（真源）：

```text
backend/app/agents/academy/packs/
  README.md
  E13/pack.yaml
  E14/pack.yaml
  EH01/pack.yaml
```

本地加长剧情正文仍可放 `docs/kb/short-drama/episodes/{id}.md`（默认不入库），与包内 `plot` 对齐即可。

---

## 3. 运行库表（只存状态，不存整部剧本）

| 表 | 粒度 | 存什么 |
|----|------|--------|
| `academy_progress` | 用户 × 集 | percent、unlocked（≥90% 解锁讨论） |
| `academy_room` | 用户 × 集 | 讨论原文、user_turns、affect |
| `academy_bot` | 角色 | 稳定 bot_id、人设/约束（可运营改） |
| `academy_bot_script` | Bot × 集 | 该角色眼中的本集剧本/剧情覆写 |
| `academy_bot_memory` | Bot × 次 | 长期自我感知追加 |
| `academy_bot_session` | Bot × 用户 × 集 | 会话记忆 |

**刻意不把整包塞进 MySQL**：包是文件/Git；库只记「这个孩子看到哪、聊了啥、Bot 记住啥」。  
以后若要运营后台热更，可再加只读缓存表 `academy_episode_pack`（episode_id PK + pack_json + revision），首版不必。

## 4. 数据结构（包 YAML）

```yaml
id: E14
title: 蒙上眼睛之后
topic: 多元感知 · 圆形教室
task: 蒙眼认一张卡
duration_label: 正片约 5:50
poster: /static/dayu/assets/miji/mj-tfsd.jpg
oss_key: AIshipin/E14_blindfold_720p.mp4   # 空 = 无正片
switchable: true
chips:
  - 戴上眼罩你怕不怕黑？
  - 你摸到卡片是什么感觉？
sense:
  yuchen: 关了灯我想到绿…
  jiahui: 红的粒子里有个黑三角…
lines:
  yuchen:
    - 关了灯我想到绿，绿漫成一大片草地。不是卡片绿，是我想到了绿。
    - 眼睛关了，脑子反而更吵。
  shanyu:
    - 眼睛关了，世界不会关。
    - 聊得热闹。聊完，心别跑。
danmaku:
  - 好眼罩了吗
  - 摸到棱了？
plot:
  can_talk: 圆形教室、眼罩、卡片、各人摸到或想到的那一下
  cannot_know: 地宫、五角迷宫、738
  teacher: 田小静
fit:
  must_have: [眼罩, 卡片, 关灯]
  must_not_alone: [站桩, 标准桩, 十桩]   # 仅有这些而无 must_have → 判串集，重开讨论
```

加载后在内存里变成 `EpisodePack`（dataclass），供 catalog / perception / sector / fake 读取。

## 5. 数据流（整条流水线）

```text
                    ┌─────────────────────────────┐
                    │  Episode Pack (YAML 真源)   │
                    │  meta / sense / lines / …   │
                    └─────────────┬───────────────┘
                                  │ load_pack(id)
          ┌───────────────────────┼───────────────────────┐
          ▼                       ▼                       ▼
   catalog.Episode          perception                 sector API
   (播放/切集目录)         sense+lines+fit            chips/notice/task
          │                       │                       │
          ▼                       ▼                       ▼
   play_url / stream        time_box + fallback      drama.html 渲染
          │                       │
          ▼                       ▼
   academy_progress         graph / harness 发言
   (看完→unlocked)                │
          │                       ▼
          └──────────► open/chat → academy_room (+ bot_session)
```

用户侧闭环：

1. `GET /sector?episode_id=` → 包 meta + 进度 unlocked  
2. 播放 → `POST /progress` → 满 90% unlocked  
3. 看片过半预取 `POST /open` → 无消息则按本集 sense/lines 开场；有消息且 fit 则 replay  
4. `POST /chat` → 多智能体按本集 time_box 接话  
5. 切集 → 换 pack；各集 progress/room 独立  

串集防护：`messages_fit_episode`（包 `fit` 或内置规则）→ 丢掉错误 room 重开。

## 6. 功能边界（固定工具流 vs 包内容）

| 固定（不要每集改代码） | 随包变 |
|------------------------|--------|
| 解锁阈值 90% | 标题 / task / chips |
| stream / CDN 播放 | oss_key |
| open / chat / LangGraph 顺序 | sense / lines / plot |
| 六角色 bot_id | 本集弹幕、本集脚本覆写 |
| 三页 sector 组装 | 是否 switchable |

加集标准动作（工具流）：

1. 新建 `packs/{ID}/pack.yaml`（可复制 E14）  
2. 上传正片到 OSS `AIshipin/…`，填 `oss_key`  
3. （可选）`docs/kb/short-drama/episodes/{ID}.md` + `index.yaml` 一条  
4. 若要进频道下拉：把 id 写入 `SWITCHABLE_IDS` 或包字段 `switchable: true` 由 loader 汇总  
5. 本地打开该集验证：切集 → 播放 → 讨论台词不串集

## 7. 与现状对照

| 现状散落点 | 迁入包后 |
|------------|----------|
| `catalog.py` 里硬编码 Episode | meta 来自 pack，catalog 合并 |
| `perception.EPISODE_SENSE/LINES` | pack.sense / pack.lines |
| `fake.js` LINES_BY_EP | 可由 sector 下发，或继续与包对齐维护 |
| `drama.html` DANMAKU_BY_EP | pack.danmaku → sector → 前端 |
| KB md | 仍本地；包 plot 作短摘要 |

首期：**loader 已读 packs**；catalog 仍保留全集目录，sense/lines **优先包、回落代码常量**。后续可把 catalog 条目也改为「只扫 packs 目录」。

## 9. 验收口径

- 同用户 E13 / E14 / EH01 讨论内容互不串台  
- 已解锁再进：恢复本集 room，不重新锁  
- 新加一集：只加 pack（+ OSS + 可选 KB），主流程代码零改或仅改 SWITCHABLE 列表  
- 包校验：必填 id/title/task；有 oss_key 则可播
