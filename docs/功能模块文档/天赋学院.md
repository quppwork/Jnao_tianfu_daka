## 定位

学生端「天赋学院」：看短剧正片 → 解锁讨论 → 与画中人聊天；历史剧情六幕与天赋课程进度跟观看记录走。  
**不是** Guide / QA 的替代，也不回答作业。

## 播放

与今日修炼同一套路：

1. `sector.play_url`：有 CDN → 签名直链；否则 → `/api/academy/episodes/{id}/stream`（可带 `mt`）
2. `GET .../stream`：鉴权后 302 CDN 或后端代理 OSS，供 `<video>` 同源播放
3. 进度：`POST .../progress`；讨论解锁看服务端规则（约 90%）
4. 结束 overlay /「加入频道讨论」：仅在 **播放 ended** 后出现，并滚到聊天区

## 讨论与弹幕

- 开房 / 聊天：`POST .../open`、`POST .../chat`
- 六个画中人独立 Bot（善雨、章宇尘、施丹尼、李寞、王家慧、陈雪）
- 前端观众弹幕：`drama.html` 按集 `DANMAKU_BY_EP`（非原生播放器开关）
- 可选：百炼短剧库 retrieve → 角色 harness 软注入（见 `agents/academy/kb.py`）
