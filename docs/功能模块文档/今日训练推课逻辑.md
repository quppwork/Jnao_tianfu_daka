# 今日训练 · 推课逻辑

> 最后更新：2026-08-23  
> 状态：与当前代码一致（v3 Decision Tree + 权重引擎）  
> 页面 UX / Part 轮换见 [今日训练.md](./今日训练.md)；历史设计稿见 [权重排课方案.md](../权重排课方案.md)

本文只写**整条推课链路**：选时长如何变成当天训练卡，以及打卡如何改第二天再推什么。豆包不参与选课。

---

## 一、一句话

用户选今日时长 → 公式按段位/学段/近史排出技能槽 → 每个槽按该技能当前 OSS 进度对上音频 → 听完打卡推进段位和课件 → 次日 4:00 用新状态再排。

```
选时长  →  公式定技能槽  →  OSS 对音频  →  打卡晋级  →  次日再排
 POST      expand_formula     populate        mastery      4:00
/schedule
```

三条线互不等待：

| 线 | 决定什么 | 谁算 |
|---|---|---|
| 每日安排 | 今天练哪些技能 | `expand_formula` |
| 技能段位 | 该技能第几段、达标线 | `training_mastery`（连续 3 次达标 +1） |
| 总段位 | 公式用哪一档权重 | `display_overall_tier`（有打卡技能的最低阶） |

## 二、入口与约束

**接口：** `POST /api/training/schedule`  
`backend/app/api/training.py` → `schedule_training_by_duration`

| 条件 | 行为 |
|---|---|
| 时长 &lt; 20 分钟 | 拒绝 |
| 未完成天赋测评 | 403 |
| 训练日切换中（凌晨 4:00 起约 5 分钟） | 503 |
| 今日已完成 | 403，次日 4:00 解锁 |
| 未开练（无观看/无打卡） | 无内容、改时长或旧结构非法 → **重生** |
| 已开练 | **禁止清表重排**；改时长 403 |

训练日：当天 04:00 ～ 次日 03:59:59（`training_day.py`）。

前端：`vue_fronted/src/pages/training/index.vue` 选时长后调 `scheduleTrainingPlan`。

## 三、排课前读哪些状态

`populate_plan_items` 组装上下文后再调公式：

| 输入 | 来源 | 用途 |
|---|---|---|
| `talent_code` | 有效天赋 | 选哪个 OSS 音频池 |
| 年级 → 学段 | `child_grade` + `_grade_band` | 小学低/高、初中、高中（阈值、扫描速记标注） |
| 总段位 | `display_overall_tier` | 决策树、权重表、可用技能 |
| 各技能段位 | `training_progress.skills.*.tier` | 第 3 段选捆绑时优先补弱项 |
| OSS `stage/part` | 同上 | **对哪一条音频**（公式不管这条） |
| 近 30 个有效排课日 | 有时长且有项的历史方案 | 近 3 日已练技能降权 |

**总段位必须走 `display_overall_tier`：** 只对「库里有打卡记录的技能」取最低阶。排课、成长页、学业规划同一函数，禁止各接口自己 `min(全部技能)`。

## 四、公式：今天练哪些技能

主函数：`training_formula_engine.expand_formula`  
规则表：`backend/config/training_curriculum.yaml`

```
时长 + 总段位 + 学段 + 技能段位 + 近史
        │
        ▼
 Layer 1  决策树
        │  总段位 == 3  → weight_with_bundle
        │  其他         → weight_based
        ▼
 Layer 2  策略流水线
        resolve_slots →（第3段 require_bundle）→ greedy_fill
        → annotate_grades → tag_electives
        ▼
 slots[]（中文技能名，按顺序）
```

旧的 7/14 天短时旁路已删。多样性靠：关键技能衰减 0.7、次要 0.5、近 3 日已练 ×0.55。

`llm_routing.enabled` 现为 `false`。豆包只可能写教练口播，不选槽、不挑课件。

### 4.1 时长 → 槽数

未落在精确档时**向下取最近已解锁档**（30 分 → 20 档 1 槽），不会误落到 ≥480。

| 今日时长 | 必修槽 | 追加 | 试卷提示 |
|---|---|---|---|
| 20 | 1 | — | — |
| 40 | 2 | — | — |
| 60–120 | 3 | — | — |
| 121–180 | 4 | 第1–2段高效作业×1；第3段起极速学习×1 | 2 套以上 |
| 181–240 | 4 | 作业×1 或 极速学习×2 | 3 套以上 |
| 241–479 | 5 | 作业×1 或 极速学习×3 | 4 套以上 |
| ≥480 | 6 | 同上 + **精力恢复** | — |

### 4.2 各段开放技能与权重

代码 A–I：阅读 / 影像 / 扫描 / 运算 / 学习 / 文奥 / 理奥 / 绘画 / 音乐。

| 总段位 | 可推 | 权重侧重 |
|---|---|---|
| 1 | A B C D E | 阅读 0.40、影像 0.35 |
| 2 | 同上 | 影像 0.35、扫描 0.25，阅读降到 0.25 |
| 3 | 同上 + 捆绑 | 影像/扫描/运算为主，阅读 0.05 |
| 4 | 同上 | 继续压阅读，运算和学习升高 |
| 5 | 加上 F G | 文奥/理奥各 0.20 |
| 6 | B C D H I | 阅读退出主槽 |

第 7–9 段配置为排除，当前不排。

### 4.3 第 3 段捆绑

先占捆绑槽，再贪心补剩余。选捆绑：搭档技能**个体段位最低**者优先。

| ID | 技能 | 占槽 |
|---|---|---|
| B1 | 多元感知 + 极速运算 | 2 |
| B2 | 扫描速记 + 极速运算 | 2（初高中标「不推荐」） |
| B3 | 影像追忆 + 极速运算 | 2 |
| B4 | 极速运算 + 极速学习 | 3（总槽须 ≥3） |

### 4.4 学段与选修

- 初中/高中：扫描速记标「不推荐」（仍可能被抽到，只是标注）。
- **必修** `blocks_next=true`，闯关按序。
- **选修** 不挡下一关：
  - 精力恢复：≥8 小时追加，不打卡
  - 高效作业：公式作业槽，不打卡
  - 多元感知：可打可不打（捆绑或手动 toggle）

## 五、槽位变成训练卡

仍在 `populate_plan_items`：

1. 清空当日旧 `TrainingItem`（仅未开练路径会走到这里）。
2. 对每个 `slot` 技能：`get_skill_oss_position` → 天赋池里匹配 `skill + stage + part`。
3. 精确匹配失败：退回该技能任意一条；再没有：占位「待同步」。
4. 补配套视频（`training_video_attach`），缺媒体再 `repair_plan_media_items`。
5. `build_coach_text_for_plan` 写口播（`report_text`）。
6. `plan.content_index` 写入当日总段位（展示用，不是旧课程序号）。

公式只输出技能名，**不指定第几阶段第几 part**。同一技能连练多天，可能技能组合变、音频也变，因为 OSS 指针已前进。

## 六、打卡如何改下次推课

`training_mastery.process_checkin_progress`，阈值在 `training_tier_thresholds.yaml`（技能段位 × 学段）。

```
提交打卡卡
  → 按该技能当前段位 + 学段判达标
  → 通过：consecutive_pass +1，bump OSS 到下一条
  → 未过：consecutive_pass 清零
  → consecutive_pass ≥ 3：该技能段位 +1，计数重置
  → 总段位 = display_overall_tier（有打卡技能的最低阶）
```

次日 4:00 新训练日再选时长：新的总段位进权重表，新的技能段位影响捆绑，新的 OSS 指针对上不同音频，近史惩罚避免天天同一技能。

## 八、和旧文档的差异（避免看串）

| 点 | 当前实现 | 勿再按旧稿 |
|---|---|---|
| 总段位 | 只看**有打卡记录**的技能取最低 | 不是 `min(配置里全部技能)` |
| 短时多样性 | 权重衰减 + 近 3 日软惩罚 | 不是 7/14 天旁路策略 |
| 时长未落档 | **向下**取最近档 | 不是回落到 ≥480 排出 6+ 项 |
| LLM | 关闭，只写口播 | 不是豆包路由 A/B 音频 |
| 一天重排 | 未开练可重生；已开练禁止 | 开练后改时长会 403 |
