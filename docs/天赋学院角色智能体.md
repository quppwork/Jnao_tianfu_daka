## 需求

六个画中人（善雨、章宇尘、施丹尼、李寞、王家慧、陈雪）是各自独立的 Bot。讨论区里用户和画中人一起说话。Bot 之间可以接话，但必须分得清谁是用户、谁是另一个 Bot。

- 每个 Bot 有稳定编号，例如 `bot_yuchen`。用户没有编号。
- 人物提示词、约束、某一集的剧本和剧情都可以上传。六个角色用同一套接口，不按人分叉。
- 每次这些配置变化，该 Bot 自己追加一条长期记忆，不覆盖旧记忆，也不写进别人的记忆。
- 每次讨论，该 Bot 另有一份会话记忆，只属于「这个 Bot + 这个孩子 + 这一集」。
- 唤醒讨论时随机点一个不是上一句说话的 Bot。开口顺序由 LangGraph 卡住：先时间，再点名，再逐个说。
- 角色只感知已经走到的剧集；后面的幕不能说。测试切集（E13 / E14 / EH01）时，感知与讨论按**当前集**隔离。

可选：百炼短剧知识库 retrieve（`agents/academy/kb.py`），软注入人设/本集笔记，不替代今日修炼，不答作业。

**一集一套资料（加集工具流）**：见 [功能模块文档/天赋学院-剧集包模块.md](./功能模块文档/天赋学院-剧集包模块.md)；包目录 `backend/app/agents/academy/packs/{集号}/pack.yaml`。

## 数据

| 表 | 存什么 |
| --- | --- |
| `academy_bot` | 编号、名字、天赋标签、当前提示词、当前约束、版本号 |
| `academy_bot_script` | 这个 Bot 眼中某一集的剧本和剧情 |
| `academy_bot_memory` | 长期自我感知，按次追加 |
| `academy_bot_session` | 会话记忆，消息里标明 user 或 peer bot |
| `academy_room` | 讨论区共享原文 |
| `academy_progress` | 看到哪一集，用来卡时间 |

---

## 技术

沿用现有栈：FastAPI、SQLAlchemy、豆包补全、LangChain 拼提示词、LangGraph 约束发言顺序。  
自我更新先写成确定性记忆，不依赖当次大模型成功。  
目录与 harness：`backend/app/agents/academy/`；房间与 sector：`backend/app/services/academy/`。

---

## 接口

- `GET /api/academy/bots`
- `GET /api/academy/bots/{bot_id}`
- `PUT /api/academy/bots/{bot_id}` 提示词和约束
- `POST /api/academy/bots/{bot_id}/episodes/{episode_id}/script` 剧本和剧情
- 讨论：`POST /api/academy/episodes/{episode_id}/open|chat`
