# JNAO 技术现状与「首个智能体应用」上架评估

> 用途：对外/协作方同步技术栈、完成度、距可上架差距。  
> 基准日期：2026-09-07 · 产品：JNAO 天赋成长平台

---

## 1. 技术栈（一句话版）

| 层 | 技术 |
|----|------|
| 前端 | **UniApp + Vue 3**（H5；可扩小程序），开发端口 5185 |
| 后端 | **Python 3 + FastAPI + Uvicorn**，端口 8012 |
| 数据 | **SQLite**（本地开发）/ **MySQL**（共享/生产）；可选 **Redis** |
| AI 对话 | **火山引擎豆包（Ark）** |
| 知识库 RAG | **阿里云百炼**（引导页主路径）；答疑侧另有遗留企业 RAG（可关） |
| 测评 | 外部 **m.jnao.com** API |
| 媒体 | **阿里云 OSS**（训练音视频签名播放） |
| 认证 | Cookie Session（`jnao_session` / 管理端独立 Cookie）+ `user_id` |
| 语音 | 火山 ASR/TTS（ASR 可接；TTS 前端未用） |
| 部署 | Docker Compose 可选；脚本一键起停 |

**智能体架构（自研，非 LangChain/LangGraph）：**

- `Guide`（首页引导）：情境注入 + 只读工具循环 + 百炼选库问答 + 前端 navigate 交接  
- `QA`（学科答疑）：分科提示词 + 豆包；与 Guide **互不调用**，靠前端跳转  
- 学业规划等：单次 LLM 生成，**不是**独立 Agent 循环  

契约文档（给无源码前端团队）：`docs/前端对接API契约.md`。  
外部依赖总览：`docs/外部接入与上游API.md`。

## 3. 「第一个智能体应用」指什么

建议口径：

> **首发智能体应用 = 已嵌入 App 的「首页引导 Guide」**  
> （张宇老师人设 · 训练情境 · 知识库问答 · 跳转训练/答疑/报告）

不是单独再做一个新 App；而是 **现有 H5/多端壳里，Guide 达到生产可用并对外发布**。

学科答疑 QA 可作为同版本或紧随的第二智能体能力，但「第一个」建议锁定 Guide。

## 4. 距上架还差什么（技术语言）

| 类别 | 差距 | 预估量级* |
|------|------|-----------|
| **运行环境** | 生产 `DATABASE_URL`（MySQL）、密钥（豆包/百炼/OSS）、CORS Origin、HTTPS Cookie | 0.5–2 人日配置+验证 |
| **知识库生产化** | 百炼索引/aid 与线上一致；脑教育 staging 包若要进检索需 Embedding/入库（可并行） | 视接手方 3–10 人日 |
| **前端发布形态** | 现网 UniApp H5 可直接发；若外部重构前端，则依赖契约联调与回归 | **不改前端**：短；**重构前端**：按对方排期（常 2–6 周+） |
| **体验/稳定性门禁** | Guide 延迟（KB 问答可达数十秒）、bootstrap LLM 失败已有模板兜底、限流与监控（biz_log） | 1–5 人日抽检与告警 |
| **合规与账号** | 短信/微信生产参数；脱敏与宣传口径（知识库已预处理） | 与业务并行 |
| **非阻塞** | TTS、Guide 多模态、中心 Orchestrator、LoRA 微调 | 明确不做或不挡首发 |

\*人日为研发侧粗估，不含法务/应用商店审核/业务运营准备。

### 时间判断（条件句）

1. **沿用现前端 + 生产环境配齐 + Guide/百炼联调通过**  
   → 距「技术可上架」大约 **1–2 周**（全力联调与冒烟），再加业务侧发版窗口。  

2. **前端整体重构、仅保证 API 不变**  
   → 智能体后端已就绪；**上架节奏由新前端交付决定**（常见再加 **数周**），后端可并行提供测试环境与契约。  

3. **必须等「独立 Agent 产品」或 LangGraph/LoRA 重做**  
   → **不建议**作为首发前置；会显著拉长周期，与当前已收口的自研 Agent **无必要绑定**。

## 5. 可对外说的技术摘要（可直接粘贴）

> 我们是 K12 AI 成长平台：**前端 UniApp/Vue3，后端 Python FastAPI**，数据 MySQL/SQLite，对话用**火山豆包**，引导知识库用**阿里云百炼 RAG**。业务上测评、训练打卡、答疑、成长、家长/管理端均已落地。  
> 智能体为**自研双 Agent（Guide + QA）**：工具循环、会话记忆、限流与交接协议已具备，**Guide 主线已收口**并可接知识库问答。  
> 「第一个智能体应用上架」指 **Guide 随主 App 生产发布**，不是从零造框架。技术侧剩余主要是**生产配置、知识库/联调与发版门禁**；在沿用现前端前提下，量级约 **1–2 周技术收口**，若前端大重构则以上架排期随前端交付。
