# 项目结构说明

> 最后更新：2026-07-23

---

## 总览

```
tianfu_daka/
├── backend/           # Python FastAPI（端口 8012）
├── vue_fronted/       # UniApp Vue 前端（Vite 5185）
├── docs/              # 项目文档
├── scripts/           # start.bat / stop_all 等
├── tests/             # 发烟 + 集成测试
├── logs/              # app.log（轮转）
└── .venv/             # Python 虚拟环境
```

---

## 后端 `backend/`

| 目录/文件 | 说明 |
|------|------|
| `main.py` | FastAPI 入口；`boot_id` 启动日志；请求日志（ping 降噪） |
| `app/core/runtime.py` | `boot_id` / 维护模式 / `force_logout` / 开发强制重登 |
| `app/core/deps.py` | 鉴权依赖；session 失败打日志 |
| `app/core/session.py`（db） | SQLite：文件库 `NullPool`，`:memory:` 用 `StaticPool` |
| `app/api/guide.py` | 首页引导：session / **bootstrap** / chat / stream / clear |
| `app/api/health.py` | `/api/ping`（含运行时标志） |
| `app/api/meta.py` | `/api/meta/version`（build_id + 维护/force_logout） |
| `app/agents/guide/` | 引导 Agent：persona / context / situations / bootstrap / runner / **tools** |
| `app/agents/shared/handoff.py` | navigate 白名单；Guide↔QA 不互调 runner |
| `app/agents/qa/` | 学科答疑 Agent |
| `app/services/` | 业务层（训练/测评/家长/会话等） |
| `tests/` | pytest |

---

## 前端 `vue_fronted/`

| 目录/文件 | 说明 |
|------|------|
| `src/pages/index.vue` | 首页：bootstrap 欢迎卡 + 引导对话 + actions |
| `src/pages/training/` | 今日训练 |
| `src/pages/login/` | 统一登录 / 注册 / onboarding |
| `src/utils/userApi.js` | HTTP + `bootstrapAppSession` |
| `src/utils/devBootAuth.js` | 开发态：后端重启清登录 |
| `src/utils/appUpdate.js` | build_id 刷新提示 + 维护遮罩 + force_logout |
| `src/utils/appSession.js` | localStorage 登录槽位 |
