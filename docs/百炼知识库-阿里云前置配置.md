> **适用范围**：文档搜索类知识库 · 中国站 **华北2（北京）**  
> **编写日期**：2026-08-24

## 一、配置总览

```
阿里云账号
  ├─ 1. 开通百炼（北京地域）
  ├─ 2. 创建 / 确认业务空间 → 拿 WORKSPACE_ID
  ├─ 3. RAM 用户 + AccessKey → 拿 AK/SK
  ├─ 4. 授权 AliyunBailianDataFullAccess + 加入业务空间
  ├─ 5. 创建 DashScope API Key（Search 检索可选）

  └─ 8. 账户余额 / 计费确认
         ↓
  backend/.env 填入对应变量 → 开始 API 接入
```

**两种建库方式（二选一即可）**：

| 方式 | 适合 | 文档 |
|------|------|------|
| **控制台手动** | 第一次验证、文档少 | 本文 §六 |
| **API 脚本** | 自动化、CI 同步 | [API接入准备 · 附录建库脚本](./百炼知识库API接入准备.md#附录完整建库-python-骨架可复制跑通) |

## 三、开通百炼服务

### 3.1 主账号首次进入

1. 登录 [百炼控制台](https://bailian.console.aliyun.com/)
2. 按提示开通「大模型服务平台百炼」
3. 同意服务协议；必要时完成实名认证
4. 确认左上角 / 页面显示地域为 **华北2（北京）**

### 3.2 确认默认业务空间

百炼以 **业务空间（Workspace）** 隔离资源。首次开通通常会自动创建一个默认空间。

**获取业务空间 ID 与 API Host**：

1. 控制台 → 左侧 **业务空间管理**
2. 在列表中复制两列：
   - **业务空间 ID**（形如 `ws-xxxxxxxxxxxxxxxx`）
   - **API Host**（形如 `{workspaceId}.cn-beijing.maas.aliyuncs.com`）

| 控制台字段 | 含义 | 用途 |
|------------|------|------|
| 业务空间 ID | Workspace ID | OpenAPI 路径参数 `workspace_id`；Search URL 前缀 |
| API Host | 空间级 HTTP 主机 | Search / 部分 MaaS HTTP 接口；**不是** OpenAPI `bailian.cn-beijing.aliyuncs.com` |

```bash
# 写入 backend/.env
WORKSPACE_ID=ws-xxxxxxxxxxxxxxxx
BAILIAN_WORKSPACE_ID=ws-xxxxxxxxxxxxxxxx   # 与上相同，代码侧别名
BAILIAN_API_HOST=ws-xxxxxxxxxxxxxxxx.cn-beijing.maas.aliyuncs.com
```

> OpenAPI（建库 / Retrieve）仍走 `bailian.cn-beijing.aliyuncs.com` + AccessKey；  
> Search HTTP 走 `https://{BAILIAN_API_HOST}/api/v1/indices/knowledge/search` + DashScope API Key。

### 3.3 JNAO 当前业务空间（已确认）

来源：百炼控制台 → 业务空间管理 → **默认业务空间**（2026-02-10 创建，华北2 北京）

| 项 | 值 |
|----|-----|
| 业务空间名称 | 默认业务空间 |
| **WORKSPACE_ID** | `ws-0w5t66cmzttowdnw` |
| **API Host** | `ws-0w5t66cmzttowdnw.cn-beijing.maas.aliyuncs.com` |
| **知识库** | `Jinao 天赋知识库` |
| **BAILIAN_INDEX_ID** | `x1micrdmjq` |

```bash
# backend/.env（业务空间部分 — 已确认可直接用）
WORKSPACE_ID=ws-0w5t66cmzttowdnw
BAILIAN_WORKSPACE_ID=ws-0w5t66cmzttowdnw
BAILIAN_API_HOST=ws-0w5t66cmzttowdnw.cn-beijing.maas.aliyuncs.com
```

**仍缺（下一步去拿）**：

| 项 | 去哪拿 | `.env` 键 | 状态 |
|----|--------|-----------|------|
| RAM AccessKey | [RAM 用户](https://ram.console.aliyun.com/users) 或复用 OSS 密钥 | `ALIBABA_CLOUD_ACCESS_KEY_ID` / `_SECRET` | 待确认 |
| 知识库 ID | 控制台 → 知识库 → 详情 | `BAILIAN_INDEX_ID` | 待建库 |
| DashScope API Key | 左侧 **API Key**（描述「知识库」） | `DASHSCOPE_API_KEY` | ✅ 已创建，写入本地 `.env`（勿提交 Git） |

弹窗里还会给出（与 API Host 同域）：

| 地址 | URL |
|------|-----|
| OpenAI 兼容 | `https://ws-0w5t66cmzttowdnw.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |
| DashScope | `https://ws-0w5t66cmzttowdnw.cn-beijing.maas.aliyuncs.com/api/v1` |

## 四、RAM 权限与 AccessKey

### 4.1 谁需要配权限？

| 身份 | 是否需要 AliyunBailianDataFullAccess | 说明 |
|------|--------------------------------------|------|
| **主账号** | 否（默认有权限） | 可直接调 API，生产不推荐 |
| **子账号 / RAM 用户** | **是** | 生产环境推荐 |
| **JNAO 后端进程** | 通过 RAM 用户的 AK/SK | 不要用主账号 AK |

### 4.2 创建 RAM 用户（推荐）

1. 打开 [RAM 控制台 → 用户](https://ram.console.aliyun.com/users)
2. **创建用户** → 勾选「OpenAPI 调用访问」
3. 记录生成的 **AccessKey ID** 和 **AccessKey Secret**（仅显示一次）

```bash
# backend/.env（可与 OSS 共用同一 RAM 用户，或单独建 jnao-bailian）
ALIBABA_CLOUD_ACCESS_KEY_ID=LTAIxxxxxxxx
ALIBABA_CLOUD_ACCESS_KEY_SECRET=xxxxxxxxxxxxxxxx
```

### 4.3 授权百炼数据策略

1. RAM 用户详情 → **权限管理** → **新增授权**
2. 选择系统策略：**`AliyunBailianDataFullAccess`**
3. 确认授权

> 该策略覆盖知识库的创建、上传、检索、切片管理等 OpenAPI 操作。

### 4.4 子账号加入业务空间（必须）

仅有 RAM 策略不够，子账号还必须被 **加入百炼业务空间**：

1. 百炼控制台 → **业务空间管理**
2. 选择 JNAO 使用的空间 → **成员管理**
3. **添加成员** → 选择刚创建的 RAM 用户
4. 赋予合适角色（开发/管理员，视团队规范）

未加入空间时调 API 会报：

```
Access denied: Either you are not authorized to access this workspace,
or the workspace does not exist
```

### 4.5 与现有 OSS 密钥的关系

JNAO 项目 `.env` 里已有 OSS 用的 AccessKey（北京 `oss-cn-beijing`）：

| 方案 | 做法 | 建议 |
|------|------|------|
| **复用** | 给现有 RAM 用户追加 `AliyunBailianDataFullAccess` | 开发阶段省事 |
| **隔离** | 新建 `jnao-bailian` 用户，仅百炼权限 | **生产推荐** |

百炼 OpenAPI 与 OSS 使用 **同一套 AK/SK 环境变量名**（`ALIBABA_CLOUD_ACCESS_KEY_*`），无需两套密钥变量。

### 4.6 安全要求

- AccessKey Secret **不要提交 Git**（已在 `.gitignore` 忽略 `.env`）
- 生产定期轮换 AK/SK
- 为 RAM 用户开启 **MFA**（控制台登录用）
- 最小权限：若后续有更小粒度策略，可替换 `AliyunBailianDataFullAccess`

## 五、DashScope API Key（Search 检索用）

OpenAPI（建库、Retrieve）用 **AccessKey**；**知识检索 Search HTTP** 用 **DashScope API Key**。

### 5.1 何时需要？

| 检索方式 | 是否需要 DashScope Key |
|----------|------------------------|
| `Retrieve`（单库，SDK） | ❌ 不需要 |
| `Search`（多库，HTTP） | ✅ 需要 |
| JNAO 引导页首版 | 建议先用 **Retrieve**，Key 可后补 |

### 5.2 创建步骤

1. 百炼控制台 → **API Key 管理**（或 [DashScope 控制台](https://dashscope.console.aliyun.com/)）
2. **创建 API Key**
3. 复制 Key（形如 `sk-xxxxxxxx`）

```bash
# backend/.env（仅 Search 模式需要）
DASHSCOPE_API_KEY=sk-xxxxxxxx
```

### 5.3 注意

- DashScope Key 与 AccessKey **不是同一个东西**
- Search 请求头：`Authorization: Bearer {DASHSCOPE_API_KEY}`
- 默认限流约 **25 QPS**（用户维度）

## 六、控制台创建知识库（推荐首次使用）

比直接跑 API 脚本更直观，适合确认文档解析效果。

### 6.1 准备文档

JNAO 引导页建议首批上传：

| 类别 | 示例内容 |
|------|----------|
| 平台说明 | 四大模块介绍、打卡规则（面向用户版，不含内部算法） |
| 训练方法 | 超脑阅读、影像追忆、扫描速记等技能说明 |
| 天赋解读 | 五者类型（学者/思者/赢者/德者/行者）说明 |
| FAQ | 家长/学生常见问题 |

**格式**：docx、pdf、txt、md、html 等（以控制台支持列表为准）  
**注意**：单文件不宜过大；敏感内部排课算法文档 **不要** 上传

### 6.2 创建步骤

1. 百炼控制台 → **知识库** → **创建知识库**
2. 类型选择：**文档搜索** / 非结构化文档
3. 填写名称，如 `JNAO-引导页知识库`
4. **上传文件** 或 选择已在上传中心的文件
5. 配置切片策略（首次可用默认）
6. 提交并等待 **索引构建完成**（状态为可用 / 已完成）

### 6.3 获取知识库 ID

索引完成后：

1. 进入该知识库详情页
2. 复制 **知识库 ID** / **Index ID**（形如 `mymxbdxxxx` 或控制台展示的 ID 字符串）

```bash
# backend/.env
BAILIAN_INDEX_ID=mymxbdxxxx
```

### 6.4 控制台验证检索

在知识库详情页使用 **检索测试** / **命中测试**：

| 测试 Query | 期望 |
|------------|------|
| `超脑阅读怎么练` | 命中训练说明切片 |
| `学者天赋是什么` | 命中天赋解读切片 |
| `今天天气怎么样` | 无相关结果或低分 |

确认有合理命中后再接后端 API。

### 6.5 与 API 建库的对应关系

| 控制台操作 | 对应 API |
|------------|----------|
| 上传文件 | ApplyFileUploadLease + PUT + AddFile |
| 解析等待 | DescribeFile |
| 创建知识库 | CreateIndex |
| 构建索引 | SubmitIndexJob + GetIndexJobStatus |

控制台建库 = API 9 步的图形化版本；**不要混用两种方式操作同一文件的上传租约流程**。

## 七、知识检索 Agent（可选，Search 多库用）

首版 JNAO 引导页用 **Retrieve 单库** 即可；若后续「引导页 + 学科」多库联合检索，再配置此项。

### 7.1 创建 Agent

1. 百炼控制台 → **知识检索服务**
2. **创建服务** → 选择要检索的知识库（可多选）
3. 配置检索策略：混排模型、Top-K、路由规则等
4. **发布** 服务（未发布会报 Agent 未发布）

### 7.2 获取 agent_id

发布后在服务详情复制 **服务 ID** / **Agent ID**（形如 `aid-xxxxxxxxxxxxxxxx`）

```bash
# backend/.env
BAILIAN_AGENT_ID=aid-xxxxxxxxxxxxxxxx
GUIDE_RAG_MODE=search    # 使用 Search 时设置
```

### 7.3 Search Endpoint 拼接

优先直接用控制台给出的 **API Host**：

```
https://{BAILIAN_API_HOST}/api/v1/indices/knowledge/search
```

等价写法：

```
https://{WORKSPACE_ID}.cn-beijing.maas.aliyuncs.com/api/v1/indices/knowledge/search
```

JNAO 示例：

```
https://ws-0w5t66cmzttowdnw.cn-beijing.maas.aliyuncs.com/api/v1/indices/knowledge/search
```

### 10.2 本地连通性验证（可选，接入前自测）

安装 SDK 后可用最小脚本验证 AK + 空间 + 知识库 ID 是否正确：

```bash
pip install alibabacloud_bailian20231229
```

```python
# tools/verify_bailian_config.py — 配置验证（勿提交含真实密钥的文件）
import os
from alibabacloud_bailian20231229 import models
from alibabacloud_bailian20231229.client import Client
from alibabacloud_tea_openapi import models as openapi
from alibabacloud_tea_util import models as util

ws = os.environ["WORKSPACE_ID"]
idx = os.environ["BAILIAN_INDEX_ID"]

cfg = openapi.Config(
    access_key_id=os.environ["ALIBABA_CLOUD_ACCESS_KEY_ID"],
    access_key_secret=os.environ["ALIBABA_CLOUD_ACCESS_KEY_SECRET"],
)
cfg.endpoint = "bailian.cn-beijing.aliyuncs.com"
client = Client(cfg)

resp = client.retrieve_with_options(
    ws,
    models.RetrieveRequest(index_id=idx, query="超脑阅读怎么练"),
    {},
    util.RuntimeOptions(),
)
nodes = resp.body.data.nodes or []
print(f"OK: {len(nodes)} chunks returned")
for n in nodes[:2]:
    print("-", (n.text or "")[:80])
```

期望输出：`OK: N chunks returned` 且内容与管理文档相关。

### 10.3 常见配置错误

| 现象 | 原因 | 处理 |
|------|------|------|
| Access denied / workspace 不存在 | 子账号未加入业务空间 或 WORKSPACE_ID 错误 | 检查空间成员 + ID |
| Specified access key is not found | AK/SK 填错或已禁用 | RAM 控制台重置密钥 |
| 检索无结果 | 索引未完成 或 文档不含相关内容 | 等索引完成 / 补文档 |
| Category is mismatched | API 上传时 category 不一致 | 统一用 `default` |
| Agent 未发布 | Search 调用未发布的 Agent | 控制台发布服务 |
| 403 / 欠费 | 账户余额不足 | 充值 |
